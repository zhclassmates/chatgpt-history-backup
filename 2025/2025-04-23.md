使用亚马逊云（Amazon Web Services，AWS）免费层搭建博客是一种非常流行的方式，尤其适合初学者或预算有限的人。下面是一个详细的步骤指南，教你如何在 AWS 免费云服务器上搭建一个博客网站。

---

## 一、准备工作

### 1. 注册 AWS 免费账户
- 访问 [https://aws.amazon.com/free](https://aws.amazon.com/free)
- 注册并完成账户验证（可能需要绑定信用卡）

### 2. 启用 EC2 服务
- 登录 AWS 控制台
- 搜索并进入 **EC2**
- 启动一个实例（注意选择免费层）

---

## 二、创建 EC2 实例

### 1. 选择 Amazon Linux 或 Ubuntu AMI
推荐选择：
- **Ubuntu Server 22.04 LTS**（免费层）

### 2. 选择实例类型
- 选择 `t2.micro`（免费层可用）

### 3. 配置安全组（端口）
- 开放以下端口：
  - 22（SSH）
  - 80（HTTP）
  - 443（HTTPS，可选）

### 4. 创建密钥对
- 创建一个密钥对并下载 `.pem` 文件，用于 SSH 登录服务器

---

## 三、连接服务器并搭建博客

### 1. 通过 SSH 登录 EC2 实例

```bash
chmod 400 your-key.pem
ssh -i your-key.pem ubuntu@your-ec2-public-ip
```

### 2. 安装必要软件

```bash
sudo apt update
sudo apt install nginx
sudo apt install mysql-server
sudo apt install php php-fpm php-mysql
```

或者，如果你想使用 WordPress：

### 3. 安装 WordPress

```bash
cd /var/www/html
sudo wget https://wordpress.org/latest.tar.gz
sudo tar -xzvf latest.tar.gz
sudo mv wordpress/* .
sudo chown -R www-data:www-data /var/www/html
```

然后配置数据库：

```bash
sudo mysql -u root
```

在 MySQL 中：

```sql
CREATE DATABASE wordpress;
CREATE USER 'wpuser'@'localhost' IDENTIFIED BY 'your_password';
GRANT ALL PRIVILEGES ON wordpress.* TO 'wpuser'@'localhost';
FLUSH PRIVILEGES;
EXIT;
```

配置 `wp-config.php`：

```bash
cp wp-config-sample.php wp-config.php
nano wp-config.php
```

替换以下部分：

```php
define( 'DB_NAME', 'wordpress' );
define( 'DB_USER', 'wpuser' );
define( 'DB_PASSWORD', 'your_password' );
```

---

## 四、配置 Nginx

编辑默认配置文件：

```bash
sudo nano /etc/nginx/sites-available/default
```

设置 root 为 `/var/www/html`，配置 index：

```nginx
root /var/www/html;
index index.php index.html index.htm;
```

并添加对 PHP 的支持：

```nginx
location ~ \.php$ {
    include snippets/fastcgi-php.conf;
    fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
}
```

然后重启 Nginx：

```bash
sudo systemctl restart nginx
```

---

## ✅ 前提条件

1. 已安装 [Visual Studio Code](https://code.visualstudio.com/)
2. 已安装 **Remote - SSH 插件**（在 VS Code 的扩展商店中搜索并安装）
3. 拿到 AWS EC2 的以下信息：
   - 公网 IP 地址（或域名）
   - `.pem` 私钥文件（你在 AWS 启动 EC2 时下载的）

---

## 🚀 步骤一：安装 Remote - SSH 插件

打开 VS Code：

- 左侧点击扩展（🧩 图标）
- 搜索 `Remote - SSH`
- 安装

---

## 🔧 步骤二：配置 SSH

1. 打开 VS Code 命令面板：

```plaintext
⇧ Shift + ⌘ Command + P
```

2. 输入并选择：

```plaintext
Remote-SSH: Open SSH Configuration File
```

3. 如果提示选择文件，选：

```plaintext
~/.ssh/config
```

4. 添加一段配置，像这样（替换你的 IP 和 pem 文件路径）：

```ssh
Host aws-ec2
  HostName your-ec2-ip
  User ubuntu
  IdentityFile /Users/你的用户名/Downloads/your-key.pem
```

✅ 示例：

```ssh
Host aws-ec2
  HostName 3.121.78.111
  User ubuntu
  IdentityFile /Users/alex/Downloads/my-ec2-key.pem
```

注意：确保 `.pem` 文件权限正确：

```bash
chmod 400 /Users/你的用户名/Downloads/your-key.pem
```

---

## 🔌 步骤三：连接服务器

1. 打开命令面板 `Shift + Command + P`
2. 输入并选择：

```plaintext
Remote-SSH: Connect to Host...
```

3. 选择刚刚配置的 `aws-ec2`

4. 第一次连接会提示“是否信任主机”，输入 `yes`

5. 连接成功后，右下角会变绿，显示 "SSH: aws-ec2"，你就可以用 VS Code 编辑 EC2 上的文件啦！

---

## 📁 打开远程目录

```
/var/www/html
```

你就可以像编辑本地文件一样，修改 WordPress 的配置了。

## ✅ 一步步排查 SSH 连不上的问题

---

### ① **检查你的 EC2 是否还在运行**
登录 AWS 控制台，打开 EC2 控制面板，确认实例状态：

- 实例是 **running**
- 有 **公网 IP 地址**
- 安全组没变（下一步会用到）

---

### ② **确认安全组开放了 SSH (端口 22)**

- 在 AWS 控制台 → EC2 实例 → 安全组 → 入站规则
- 应该有一条像这样：

```text
类型：SSH
协议：TCP
端口范围：22
来源：0.0.0.0/0 （或你自己的 IP 地址段）
```

> 如果你是公司网络，有些防火墙可能屏蔽 22 端口，可以临时用手机热点试下。

---

### ③ **确认你连接的 IP 地址没变**

很多 AWS EC2 的公网 IP 是“动态的”，你重启实例后 IP 会变。

你可以：

```bash
ping your-ec2-ip
```

看能否 ping 通。如果 IP 变了，记得去 `.ssh/config` 或 VS Code SSH 连接里更新新的 IP。

---

### ④ **确认 pem 密钥权限没问题**

```bash
chmod 400 your-key.pem
```

如果权限太开放（如 644），SSH 会拒绝使用这个密钥。

---

### ⑤ **手动尝试 SSH 登录看看有什么报错**

在终端运行：

```bash
ssh -i /路径/your-key.pem ubuntu@your-ec2-ip
```

看看报什么错。我可以帮你分析错误信息。

如果你在 AWS 上运行的是 Ubuntu 系统的 EC2 实例，想要**恢复初始化（重置系统）**，有几种方式可以选择，具体取决于你要“恢复到什么程度”：

---

## ✅ 选项 1：**重新创建 EC2 实例（最干净、最彻底）**

如果你想把系统恢复到最初刚装好的 Ubuntu 状态，最简单的做法是：**销毁原实例，重新创建一个新的 Ubuntu 实例**。

### 步骤：

1. 登录 AWS 管理控制台
2. 停止并终止当前 EC2 实例（⚠ 注意数据会丢）
3. 点击 **“启动实例”**，选择 Ubuntu AMI，重新建一个新的实例
4. 重新配置安全组、密钥对等

✅ 优点：
- 纯净新环境，无需手动清理
- 适合新手，最快最省事

---

## ✅ 选项 2：**保留实例，恢复系统文件（不推荐给新手）**

如果你不想重建实例，也可以通过登录系统后手动清理和恢复系统配置，比如：

```bash
sudo apt-get update && sudo apt-get upgrade
sudo apt-get install --reinstall ubuntu-desktop
```

但这通常只能“部分恢复”，比如你安装了 WordPress、改了系统文件，那就要一个个手动回退。

---

## ✅ 选项 3：**挂载磁盘清理法（稍进阶）**

如果你实例崩了登录不上，可以：

1. 创建一个新的 Ubuntu 实例
2. 将原有的 EBS（根卷）挂载到这个新实例上作为数据盘
3. 用 `sudo mount` 挂载分区，清理错误文件或备份数据
4. 恢复后再重新挂回原实例或新建实例用

适合数据重要但系统坏掉的情况。

---

## ✅ 推荐：使用 Amazon Machine Image (AMI) 快照功能

以后你可以在系统配置好后，创建一个快照（AMI）：

```bash
EC2 控制台 → 实例 → 操作 → 镜像和模板 → 创建映像
```

以后出问题可以用它快速恢复，不用从头配置 WordPress、MySQL 等。

   - VS Code 的 `.ssh/config`

### ❸ **安全组没有允许入站流量**
你可能的安全组配置缺失了允许访问的规则。

✅ 进入 EC2 控制台 → 安全组 → 入站规则  
确认是否有：

```

来源：0.0.0.0/0（或你的公网 IP 地址段）

```
类型：ICMP - IPv4
协议：Echo Request
来源：0.0.0.0/0
