# ✅ 摄像头 + 激光线布置与使用详解

你的目标是用摄像头**拍到清晰的激光线打在物体表面的曲线**，用于后续图像处理与点云重建。

---

## 🎯 一、系统原理简述

激光线模组从一侧斜照物体，打出一道红线。物体有凹凸时，红线会产生“弯曲”。  
摄像头正对物体，拍下每个角度下的激光线图像，通过分析红线轮廓，可以恢复 3D 表面。

---

## 🧩 二、硬件布置建议（俯视图）

```
         激光模组（斜角照射）
           \
            \        摄像头（正面）
  物体  O ----+-----> 📷 C270
             ↑
         旋转台中心
```

| 元件     | 摆放建议                                  |
|----------|-------------------------------------------|
| 激光模组 | 与摄像头成 **30°～45°夹角** 从侧面照射     |
| 摄像头   | **正对旋转台中心**，不跟随旋转              |
| 物体     | 放在旋转台中央，垂直放置                   |

> 📌 摄像头和激光模组都要 **固定不动**，只有物体随着旋转台转动！

---

## 🔧 三、安装与调焦建议

### ✅ 激光线模组：

- 使用的是“激光打线”模组（带柱状透镜）
- 用热熔胶或夹具将其 **斜向照射物体一侧**
- 距离物体 10～20cm 效果最好
- 使用 5V 或 USB 模块供电即可

---

### ✅ 摄像头 Logitech C270：

- 建议用小三脚架或夹具固定，**高度与旋转台中心齐平**
- 使用 Logitech Camera Settings 工具或 OpenCV 对焦
- 打开时拍摄画面应如下图所示：

```
画面中央是物体，激光线呈红色清晰可见：
┌────────────────────┐
│                    │
│         O          │
│        /█\         │ ← 红色激光线弯曲
│         █          │
│        / \         │
│                    │
└────────────────────┘
```

## 🧪 四、图像采集调试技巧

### ✅ 检查激光线是否清晰：

1. 运行下面 Python 脚本实时查看摄像头画面
2. 关闭房间主灯，**避免白光干扰**
3. 激光线应为“亮红色线”，背景尽量暗

```python
import cv2

cap = cv2.VideoCapture(0)
while True:
    ret, frame = cap.read()
    if not ret:
        break
    cv2.imshow("Camera Preview", frame)
    if cv2.waitKey(1) == 27:  # ESC 键退出
        break

cap.release()
cv2.destroyAllWindows()
```

## 🎯 五、采集效果目标示例

成功图像应该满足以下条件：

| 要素         | 描述                        |
|--------------|-----------------------------|
| 清晰         | 红线明显，无虚焦             |
| 背景干净     | 尽量暗或黑，提升对比度         |
| 激光线连续   | 在物体上是一条完整的红色线     |
| 不过曝       | 激光不要太亮导致周围发白溢出    |

## 🧰 六、激光线提取预处理建议（图像处理预告）

在后续处理中我们会使用：
- 灰度图
- 二值化或红色通道提取
- 激光线轮廓提取（坐标）

```python
gray = cv2.cvtColor(frame, cv2.COLOR_BGR2GRAY)
_, thresh = cv2.threshold(gray, 200, 255, cv2.THRESH_BINARY)
```

或使用红色通道增强：

```python
r_channel = frame[:, :, 2]
_, thresh = cv2.threshold(r_channel, 180, 255, cv2.THRESH_BINARY)
```

## ✅ 七、小贴士

| 问题                   | 建议                               |
|------------------------|------------------------------------|
| 激光线不清晰             | 关灯、远离光源、调整模组角度             |
| 摄像头看不全旋转台       | 增加摄像头距离、提高安装位置              |
| 红线曝光过度             | 用低亮度激光模组、用偏暗背景                |
| 物体反光太强             | 用哑光材质（如白色塑料、泡沫等）            |
