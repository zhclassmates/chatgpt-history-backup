## ✅ 原因解析：

SolidWorks 启动时会尝试载入默认模板（如 `Part.prtdot`、`Assembly.asmdot`、`Drawing.drwdot`），如果：

- 你没装中文/英文默认模板；
- 安装路径不标准；
- 文件丢失或权限不对；

就会出现这个报错。

---

## ✅ 快速修复方法（建议永久修好，不点“继续”）：

### 🛠 步骤如下：

1. 打开 SolidWorks
2. 点击顶部菜单：
   ```
   工具 → 选项（最下方齿轮按钮）→ 系统选项 → 默认模板
   ```

3. 勾选「**提示我选择模板**」（推荐）：
   - 这样每次你新建时，会弹出选择窗口，不会报错

4. 点击：
   ```
   文件位置 → 文档模板
   ```
   检查路径是否包含：
   ```
   C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2022\templates
   ```
   或类似路径，如果为空，请手动加上。

5. 点击“确定”，关闭设置对话框。

---

### ✅ 然后测试打开你生成的 `.STEP` 文件：
