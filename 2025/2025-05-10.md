- 每贴一部分，就修正缩进、段落、标题等格式。

## 15:34 什么是JSON格式

来源：681f0186-5448-8006-a1cd-643cff53fb91
时间：2025-05-10 15:34

### 我
<!-- mid: 8aa9ea59-7fbb-4cc2-a690-8b67b95c7715 -->
json 是什么格式

### AI
<!-- mid: 6b846d86-250a-40c8-b4b1-e3fba2244860 -->
JSON（JavaScript Object Notation）是一种轻量级的数据交换格式，广泛用于前后端通信、配置文件、数据存储等。它基于键值对结构，格式清晰、易于阅读和编写。其结构和语法类似于 JavaScript 的对象和数组。

### JSON 的基本格式：

```json
{
  "name": "Alice",
  "age": 25,
  "isStudent": false,
  "skills": ["Python", "JavaScript"],
  "address": {
    "city": "Beijing",
    "zip": "100000"
  }
}
```

### JSON 的基本规则：

1. **数据结构**：
   - 对象（Object）：用 `{}` 包裹，包含若干个 `"key": value` 键值对。
   - 数组（Array）：用 `[]` 包裹，里面是多个值，可以是对象、数组或基本类型。

2. **键必须用双引号括起来**，如 `"name"`。
3. **值可以是**：
   - 字符串（string）：`"hello"`
   - 数字（number）：`123` 或 `3.14`
   - 布尔值（boolean）：`true` 或 `false`
   - 空值（null）
   - 对象（object）
   - 数组（array）

4. **不允许注释**（和 JavaScript 不同）。
