结论：日本服务器（JP-verify）=“交易所只读核验 + 证据生成 + Merkle 根产出 + 上游回传”。对外暴露 8082。无资金托管，不写链，仅把 root 与摘要回传到美区后端或触发上链。

# 1) 角色与边界
- 负责：OKX/币安订单核验、强平/ADL 判定、证据 JSON 归档、Merkle Root 计算、健康与指标。
- 不负责：前端页面、用户账户管理、资金与合约转账、长期密钥存储。
- 目标输出：`{eligible, reasons, orderSummary, evidence: {root, ordIdHash, files}}`

# 2) 对外接口（北向，给前端/US 后端）
- `GET /healthz`：时间偏差、自身版本、依赖可用性、uptime。
- `GET /metrics`：Prometheus 指标（请求量、p95 时延、429/401 计数、外部 API 成功率）。
- `POST /api/verify`
  - 入参：  
    - `exchange`: `"okx" | "binance"`  
    - 订单标识：OKX 用 `ordId|clOrdId` + `instId`；币安用 `orderId|origClientOrderId` + `symbol`  
    - 运行标志：`live`、`fresh`、`noCache`  
    - 临时密钥（可选，仅本次调用）：OKX `apiKey/secretKey/passphrase`；币安 `apiKey/secretKey`
  - 出参：  
    - `ok`、`status`、`eligible`、`reasons[]`  
    - `orderSummary`（state/status、数量、均价、方向、时间、交易对、账户后四位标识可选）  
    - `evidence`：`{root, ordIdHash, path, leafCount, ts}`  
    - `debug`（已脱敏：`timestamp`、`requestPath`、`qsKeys`）
- `GET /api/evidence/:ordId`
  - 出参：`summary.json`、`merkle.json`、`meta.json` 的合并视图（脱敏）。
- `POST /api/evidence/attest`（可选开关）
  - 入参：`{root, ordIdHash, summaryDigest}`  
  - 动作：把 root 推送到 US 后端 `/admin/evidence/import` 或触发“上链服务”。

# 3) 对内调用（南向，出站到交易所/上游）
- OKX：`/api/v5/trade/order`、`/api/v5/public/time`（校时），必要时补充 `fills`/`positions` 与 `liquidation-history`。
- 币安：`/fapi/v1/order`、`/fapi/v1/time`，必要时补充 `userTrades` 与 `adlQuantile`。
- 上游 US：`/admin/evidence/import` 或 `/attest`（bearer 鉴权）。

# 4) 判定与规则（V1 可落地）
- **是否成交**：OKX `state in ['filled','partially_filled']`；币安 `status in ['FILLED','PARTIALLY_FILLED']`。
- **是否强平/ADL**：  
  - 可观测字段命中强平标识或在订单完成时账户持仓被强平记录覆盖。无直接字段时，辅以 `fills/positions/liquidation-history` 二次确认。  
  - 结论字段：`{eligible: boolean, reasons: ['liquidated'|'adl'|'not_liquidated'|'no_match'|'signature_error'|'rate_limited']}`。
- **幂等与缓存**：同一 `(exchange, ordId|clOrdId, instId|symbol)` 计算出的 `root` 固定；`fresh` 跳过缓存。

# 5) 证据与存储
- 目录：`evidence/<ordId>/`  
  - `raw.json`（原始交易所响应，敏感字段脱敏）  
  - `summary.json`（订单要点：状态、数量、均价、时间、方向、交易对）  
  - `leaves.json`（叶子数组，字段最小完备：`exchange, ordRef, instOrSymbol, stateOrStatus, qty, avgPx, ts`）  
  - `merkle.json`（`{root, leafCount, parentRoot, createdAt}`）  
  - `meta.json`（调用环境、版本、校时偏差、签名算法）
- SQLite（轻存档）：  
  - `evidence(id, exchange, ord_ref, inst_or_symbol, root, leaf_count, created_at)`  
  - `requests(id, exchange, ord_ref, status, latency_ms, code, created_at)`  
  - `attestations(id, root, tx_hash NULL, status, upstream_ref, created_at)`  
- **只上链 root**；`raw.json` 永不上链，仅本机留存；`parentRoot` 形成可审计哈希链。

# 6) 安全与合规
- 密钥只进内存，不落盘；请求体密钥优先，空则用环境变量测试位；响应与日志不回显密钥。
- 入口限流：IP+账户维度；外呼指数退避+抖动；尊重交易所 `Retry-After`/`X-MBX-USED-WEIGHT`。
- CORS：仅允许 US 后端与受控前端域；默认拒绝通配。
- 校时：Chrony；`skewMs>1000` 时 `/healthz` 置 `ok=false` 并拒绝签名请求。
- 网络：出站固定 IP；支持上游白名单；禁止代理篡改。

# 7) 运维与环境
- 端口：`8082`；进程：`uvicorn app:app --host 0.0.0.0 --port 8082`（或单进程 Gunicorn+UvicornWorkers）。  
- 关键环境变量：  
  - `PORT=8082`、`LOG_LEVEL=info`、`STORAGE_DIR=/var/lib/jp-verify/evidence`、`SQLITE_PATH=/var/lib/jp-verify/ev.sqlite`  
  - `ALLOW_ORIGINS=https://your-us-host`  
  - `ATTEST_UPSTREAM_URL`、`ATTEST_BEARER`  
  - `CACHE_TTL_SEC=60`、`MAX_RETRIES=3`  
  - `OKX_BASE=https://www.okx.com`、`BINANCE_BASE=https://fapi.binance.com`
- 健康检查：`/healthz`、`/metrics`；系统级：`systemd` 服务、`journalctl -u jp-verify -f`。
- 备份策略：只备份 `evidence/*/summary.json|merkle.json|meta.json` 与 SQLite；排除 `raw.json`。

# 8) 错误映射（最少集）
- HTTP 401/403：签名或白名单；返回 `reasons=['signature_error']`，给出 `debug.timestamp` 与 `prehash_len`。  
- HTTP 429/418：限流；`reasons=['rate_limited']`，告知重试窗口。  
- 404/0 行匹配：`reasons=['no_match']`。  
- Skew>1s：`reasons=['clock_skew']`。  
- 5xx/网络：`reasons=['upstream_error']`。

# 9) 验收清单（你用这 10 条验收）
1. `GET /healthz` 返回 `ok=true` 且 `skewMs<=1000`。  
2. `POST /api/verify`（OKX，真实 ordId+instId）→ `200`，含 `orderSummary` 与 `evidence.root`。  
3. 同上一条（币安，orderId+symbol）。  
4. 故意改错密钥 → `401` 且 `reasons` 含 `signature_error`。  
5. 连续高频请求 → 出现 `429` 且服务端退避生效，`/metrics` 计数递增。  
6. `GET /api/evidence/:ordId` 返回 `root` 与 `leafCount`，`raw.json` 不外泄。  
7. 打开 `fresh=true` → 不命中缓存，外呼确实发生。  
8. 停 NTP 造成 `skew>1s` → `/healthz` 报警且 `POST /api/verify` 拒绝。  
9. 开启 `POST /api/evidence/attest` → US 后端收到同一 `root` 幂等。  
10. 重启进程或主机 → 证据目录与 SQLite 均可恢复查询。

# 10) 未来扩展位（非本期）
- 增加 `/api/verify/batch` 批量验证；  
- 证据导出签名包（ZIP + detached signature）；

# 五、TypeScript 类型与 SDK（给前端直接用）
```ts
// types
export type Exchange = "okx" | "binance";
export interface VerifyReq { exchange: Exchange; ordId?: string; clOrdId?: string; instId?: string; symbol?: string; live?: boolean; fresh?: boolean; noCache?: boolean; }
export interface Evidence { root: string; ordIdHash: string; leafCount: number; ts: string; }
export interface VerifyResp { ok: boolean; status?: number; eligible?: boolean; reasons?: string[]; orderSummary?: any; evidence?: Evidence; debug?: any; error?: { code?: number|string; message?: string }; }
// client
export async function verifyOrder(base: string, body: VerifyReq, signal?: AbortSignal): Promise<VerifyResp> {
  const r = await fetch(`${base}/api/verify`, { method: "POST", headers: {"Content-Type":"application/json"}, body: JSON.stringify(body), signal });
  const j = await r.json(); return j;
}
export async function getEvidence(base: string, ordId: string) {
  const r = await fetch(`${base}/api/evidence/${encodeURIComponent(ordId)}`);
  return r.json();
}
```

## 代码级最小改造（回退与限流）
### Node.js（伪代码，放在你的 us-backend 网关）
```js
import PQueue from "p-queue";
const queue = new PQueue({ concurrency: 3, interval: 1000, intervalCap: 10 });

async function callGemini(payload) {
  const res = await fetch(GEMINI_URL, { method: "POST", headers, body: JSON.stringify(payload) });
  if (res.status === 429) throw new Error("RATE_LIMIT");
  if (!res.ok) throw new Error(`HTTP_${res.status}`);
  return res.json();
}

async function callOpenAI(payload) { /* 你的备用模型实现 */ }

export async function generate(payload) {
  return queue.add(async () => {
    // 简单缓存键
    const key = JSON.stringify(payload);
    const hit = cache.get(key);
    if (hit) return hit;

    try {
      const out = await callGemini(payload);
      cache.set(key, out, 24 * 3600);
      return out;
    } catch (e) {
      if (e.message === "RATE_LIMIT") {
        // 回退到备用模型
        const out = await callOpenAI(payload);
        cache.set(key, out, 24 * 3600);
        return out;
      }
      throw e;
    }
  });
}
```
