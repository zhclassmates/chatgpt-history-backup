## 3 · 域名 & 入口层抗告警技巧

1. **多域名热切换**：传统 DNS 易被封，可配置 Cloudflare Workers 自动把根域流量转发到最新子域或 IPFS 网关。  
2. **ENS / Unstoppable Domains**：把 IPFS hash 绑定在 `.eth` 或新顶级域下，通过浏览器插件或支持 Web3 DNS 的浏览器访问。  
3. **静态站+JSON 索引**：将核心内容拆成只读静态文件，入口页写一段脚本动态解析最新节点列表（Matrix room list / Nostr relay list / IPFS hash），减少单点失效概率。

## 2. H5 × Progressive Web App（PWA）

- **做成离线可用**：打包时加 Service Worker，首访缓存核心资源。即使上游网关被封，老用户仍能离线访问。
- **版本热切换**：把 `sw.js` 里写死的 `CACHE_VERSION` 换成 IPFS/Arweave 的最新哈希；每次你重新发布，用户刷新就拿到新包。
- **安装到桌面**：在 Android/桌面 Chrome 里可 “添加到主屏幕”，体验接近原生 App，无需上架商店。

---

## 3. Hybrid 壳 + 离线包

| 技术 | 用途 | 不易举报点 |
|------|------|-----------|
| **Tauri / Capacitor** | 把 H5 包封进跨端 WebView，产出 macOS/Windows/Linux/Android/iOS 可执行文件 | 被举报时换下载链接即可；移动端还能旁加载（Android APK / iOS TestFlight） |
| **MiniApp “外壳”** | 比如微信/支付宝小程序只提供最小壳，真正 UI 通过 WebView 拉外部 H5 | 小程序审核只看壳，内容换域名或用 IPFS 网关即可旁路 |

---

## 4. 动态协作层（可选）

如果你的 H5 页面需要多人同时编辑、留言甚至直播弹幕，可用 **WebRTC + CRDT**：

1. UI 仍是纯前端（Y.js / Automerge）。
2. 信令服务器放到 Cloudflare Workers → 被封改地址就行；数据流是点对点，没单点可举报。
3. 最后把前端代码再按上面第 1 节流程部署。

---

## 5. 入口层策略

- **多 DNS 供应商 + 自动轮换**：脚本监测某域名被封就自动切到备用域。
- **ENS / Unstoppable / SpaceID**：把 IPFS Hash 写到 Web3 DNS 记录，让支持插件的浏览器直达。
- **.onion / I2P 镜像**：给深度用户备用；能用脚本在首页动态列出可用入口。

---

## 6. 小结

> **H5 本质就是一堆静态文件。**  
> **“抗举报”关键 = 静态包去中心化存储 + 入口层热切换 + 离线缓存/PWA。**

- **存储层**：Fleek Network、Crust + IPFS、Arweave/ar.io —— 选一个或多重备份。  
- **分发/CDN 层**：去中心化边缘网络（Fleek Edge）或自己多网关、多域名。  
- **体验层**：PWA 或 Hybrid 壳，保证即使首个入口被封，用户仍能打开已缓存版本。  

这样做虽然不能 100 % 免除法律责任，但**确实比传统云主机 / Telegram 群更难“一键下架”**，且全部技术栈都已在 2024-2025 年大规模生产可用。需要进一步的打包脚本或自动化部署示例，再告诉我！

<html>

  <meta charset="utf-8" />

  <script src="https://unpkg.com/matrix-js-sdk@23.4.0/lib/browser-index.js"></script>

const client = matrixcs.createClient("https://matrix.example.com");   // ← 换成你的 homeserver
client.loginWithPassword("visitor", "SuperTempPwd").then(() => {
  client.startClient();
  client.on("sync", (state)=>{
      if(state === "PREPARED"){
        const roomId = "#tech-underground:example.com";               // 房间别名

      }

         const div=document.getElementById("log");
         div.innerHTML += `<p><b>${event.getSender()}:</b> ${event.getContent().body}</p>`;
         div.scrollTop = div.scrollHeight;
      }
  });
});

function send(){

  client.sendTextMessage("#tech-underground:example.com", body);
  document.getElementById("msg").value="";
}
</script>
</body>
</html>

## 为什么钱包不会自动恢复

| 钱包扩展 | 私钥存放位置 | 是否随浏览器同步 | 恢复手段 |
|----------|-------------|------------------|----------|

- 钱包私钥 = 最高权限，开发者不会把它丢上 Google Sync 这种第三方云。

### 📜 `split_mp4_for_rvc.py` 脚本

```python
import os
import ffmpeg
import webrtcvad
import librosa
import soundfile as sf
from pydub import AudioSegment
from tqdm import tqdm

def extract_audio_from_mp4(mp4_path, output_wav):
    print("🎧 正在提取音频...")
    ffmpeg.input(mp4_path).output(output_wav, ac=1, ar=16000).overwrite_output().run()
    print(f"✅ 提取完成: {output_wav}")

def vad_split(wav_path, output_dir, aggressiveness=3):
    os.makedirs(output_dir, exist_ok=True)
    audio, sr = librosa.load(wav_path, sr=16000)
    audio_pcm = (audio * 32768).astype("int16").tobytes()

    vad = webrtcvad.Vad(aggressiveness)
    frame_duration = 30  # ms
    frame_bytes = int(16000 * frame_duration / 1000) * 2

    segments = []
    start_idx = None
    for i in range(0, len(audio_pcm), frame_bytes):
        frame = audio_pcm[i:i + frame_bytes]
        if len(frame) < frame_bytes:
            break
        if vad.is_speech(frame, 16000):
            if start_idx is None:
                start_idx = i
        else:
            if start_idx is not None:
                segments.append((start_idx, i))
                start_idx = None
    if start_idx:
        segments.append((start_idx, len(audio_pcm)))

    print(f"✂️ 发现 {len(segments)} 段语音片段，正在保存...")

    count = 0
    for i, (start, end) in enumerate(tqdm(segments)):
        start_sec = start / 2 / 16000
        end_sec = end / 2 / 16000
        clip = audio[int(start_sec * 16000):int(end_sec * 16000)]
        if len(clip) < 16000:  # 少于1秒跳过
            continue
        save_path = os.path.join(output_dir, f"{str(count).zfill(5)}.wav")
        sf.write(save_path, clip, 16000)
        count += 1

    print(f"🎉 已输出 {count} 段音频到 {output_dir}")

def process_video(mp4_path, output_dir="dataset_ready"):
    temp_wav = "temp_extracted.wav"
    extract_audio_from_mp4(mp4_path, temp_wav)
    vad_split(temp_wav, output_dir)
    os.remove(temp_wav)

if __name__ == "__main__":
    import argparse
    parser = argparse.ArgumentParser()
    parser.add_argument("--input", required=True, help="输入的MP4文件路径")
    parser.add_argument("--outdir", default="dataset_ready", help="输出音频段的文件夹")
    args = parser.parse_args()

    process_video(args.input, args.outdir)
```
