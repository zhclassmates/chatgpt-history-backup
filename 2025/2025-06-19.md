下面给你一份「能立即开干」的技术落地方案——用 6 周时间完成一个“真人面试”微信小程序（Candidate App）和一个配套的管理后台（Interviewer Console）。流程是：**登录 → 随机出题 → 录制/实时面试 → AI / 人工评分 → 结果反馈**。

## 1. 总体架构

| 层 | 组件 | 说明 |
|---|---|---|
| **前端** | 微信小程序 (WXML / WXSS / JS) | 候选人端：题目展示、摄像 & 录音、结果页<br>面试官端（H5 或小程序插件）：实时面试或评分面板 |
| **音视频** | `live-pusher` + `live-player` 组件或 `wx.createCameraContext()` 录制 | 一对一实时面试选 `live-pusher / live-player`，<br>自录式面试选本地录制+上传 citeturn0search0turn0search2 |
| **后端** | 腾讯云 TCB / CloudBase | 云函数：抽题、签名上传、评分<br>NoSQL DB：题库、面试会话、成绩 |
| **AI 服务** | 腾讯云 ASR + OpenAI /GPT 或自建 LLM | 语音转文本 → AI 评分（见 §4） |
| **存储/CDN** | COS 对象存储 | 视频/音频文件、评分报告 JSON |
| **第三方** | TRTC 或腾讯会议 SDK（可选） | 若需要高质量实时视频面试 citeturn0search4 |

## 3. 核心功能拆解

### 3.1 题库 & 抽题

1. Excel → JSON → 导入 `questions` 集合。  
2. `getQuestions()` 云函数：按职位/难度随机抽 N 题并返回。  
3. 随机顺序 + 时限避免背题。

### 3.2 录制 / 实时面试

| 方案 | 亮点 | 适用场景 |
|------|------|------|
| **本地录制 + 上传** | 延迟低、实现简单；用 `wx.createCameraContext().startRecord({timeout: 300000})`，录制 5 min，自动停止。参考 AI 面试产品常见做法 citeturn0search1 | 大批量初筛 |
| **TRTC 实时视频** | 真正面对面；支持共享题面；评分可同时进行 | 高端岗位、群面 |

### 3.3 上传与进度提示

```js
const uploadTask = wx.uploadFile({
  url: signedUrl,
  filePath: tempVideoPath,
  name: 'file',
  success: res => {/* … */}
});
```

- 断点续传（COS SliceUpload）。  
- 进度条绑定 `uploadTask.onProgressUpdate`.

### 3.4 自动评分流程

1. **转写**：Tencent ASR 词级别转写 → `transcriptUrl`.
2. **AI 评分**：  
   ```python
   prompt = f"""
   你是HR面试官。题目：{question_text}
   候选人回答（文本）：{transcript}
   请按 rubric 给出0-5分，并给出一句建议。
   rubric: {rubricJSON}
   """
   ```
3. **生成 scoreJSON**：存入 `scores`。

> 如果想避免平台外流，可用讯飞星火、月之暗·DeepSeek API 等国内模型。

### 3.5 人工复核（可选）

- 管理后台 (H5)：列表 → 播放器 → 勾选分数 + 评语。
- 操作即写回 `scores` 表；若 AI 分与人工分差距 > 阈值触发通知。

### 3.6 结果反馈

- 小程序 `pages/result`：仪表盘 (总分 + 各维度雷达图)  
- `WxGroupShare`：一键将成绩单长图发给 HR 群。

## 4. 关键技术点 & 代码片段

### ▸ 抽题云函数（TypeScript）

```ts
export const main = async (event) => {
  const { category, count = 5 } = event;
  const db = cloud.database();
  const res = await db.collection('questions')
      .aggregate()
      .match({ category })
      .sample({ size: count })
      .end();
  return res.list;
};
```
