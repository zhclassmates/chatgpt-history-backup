## 3️⃣ 连接 Killper 设备  
根据你 Killper 上位机的 **接口类型**，有不同配置方式：  

### 🔹 如果 Killper 通过 **USB/串口** 连接  
- 在 VirtualBox 里：启用 **USB 控制器**，把设备加到 USB 过滤器里  
- 在 VMware 里：插上设备后，虚拟机菜单 → `Removable Devices` → 把 USB 设备连接到虚拟机  
- 在 Linux 里，设备会映射为 `/dev/ttyUSB0` 或 `/dev/ttyACM0`，可以用  
  ```bash
  dmesg | grep tty
  ```
  来确认  

### 🔹 如果 Killper 通过 **网口（以太网/TCP/IP）** 连接  
- 把虚拟机网络模式改成 **桥接模式（Bridge）**，这样虚拟机和 Killper 处在同一个网段  
- 在 Linux 中 `ping 设备IP` 测试是否能通  
- 通过 ssh/telnet 或者 Killper 提供的软件进行通信  

### 🔹 如果 Killper 通过 **CAN/RS485/Modbus** 等方式连接  
- 需要额外的转接器（USB-CAN、USB-RS485 等）  
- 驱动安装在虚拟机 Linux 中后，会映射成 `/dev/ttyUSBx` 设备

# 1️⃣ 在 Windows 上安装虚拟机软件  

推荐：**VirtualBox**（免费，轻量）  
下载地址：[https://www.virtualbox.org/](https://www.virtualbox.org/)  

安装完成后，再安装 **VirtualBox Extension Pack**（支持 USB2.0/3.0 直通）。  

---

# 2️⃣ 安装 Linux 系统  

选择：**Ubuntu Server 20.04 LTS**（稳定，社区支持好）  
下载地址：[Ubuntu Server ISO](https://releases.ubuntu.com/20.04/)  

创建虚拟机：  
- 类型：Linux → Ubuntu (64-bit)  
- 内存：2GB（推荐 4GB）  
- 硬盘：20GB+  
- 网络：**桥接模式 (Bridge)**  
- USB：开启 3.0 控制器  

安装 Ubuntu Server → 创建普通用户，记住用户名/密码。  

---

# 3️⃣ 配置虚拟机 USB/网络  

- **USB 直通**：  
  - 插上 3D 打印机 USB  
  - VirtualBox → 设置 → USB → 添加过滤器 → 选择打印机设备  
  - 启动虚拟机后，Linux 会识别成 `/dev/ttyUSB0`  

- **网络桥接**：  
  - 确保虚拟机和 Windows 在同一局域网内  
  - Linux 内执行：  
    ```bash
    ip a
    ```  
    找到分配的 IP（如 192.168.1.xxx），后续用这个 IP 访问 Mainsail/Fluidd。  

---

# 4️⃣ 安装 Klipper 环境  

进入 Linux，更新软件包：  
```bash
sudo apt update && sudo apt upgrade -y
sudo apt install git python3-pip -y
```

安装 KIAUH（Klipper Install And Update Helper）：  
```bash
cd ~
git clone https://github.com/th33xitus/kiauh.git
cd kiauh
./kiauh.sh
```

KIAUH 菜单里：  
- 安装 **Klipper**  
- 安装 **Moonraker**（API 服务）  
- 安装 **Mainsail** 或 **Fluidd**（网页控制界面）  

---

# 5️⃣ 编译并烧录 Klipper 固件  

在 Linux 虚拟机里：  
```bash
cd ~/klipper
make menuconfig
```

根据你主控板（如 STM32F103, STM32F407 等）选择参数，保存退出，然后：  
```bash
make
```

连接打印机主板（USB 直通必须成功），找到串口：  
```bash
ls /dev/serial/by-id/
```

烧录固件：  
```bash
make flash FLASH_DEVICE=/dev/serial/by-id/xxxx
```

---

# 6️⃣ 配置 printer.cfg  

在 Linux 中：  
```bash
cd ~/printer_data/config
nano printer.cfg
```

👉 从 [Klipper 配置库](https://github.com/Klipper3d/klipper/tree/master/config) 找到与你打印机/主板相似的 `printer.cfg`，修改串口路径 `/dev/serial/by-id/...`。  

保存并重启 Klipper 服务：  
```bash
sudo service klipper restart
```

---

# 7️⃣ 网页访问  

在 Windows 浏览器中访问：  
```
http://<虚拟机IP>
```
就能看到 **Mainsail / Fluidd 控制界面**，可以上传 G-code、调试打印机、设置参数。
