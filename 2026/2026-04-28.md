## 现在只剩 3 个真实原因（按概率排序）

```bash

```

👉 直接删或注释掉：

```bash

### ② sshd 启动了，但“秒踢人”

- `Connection closed`
- `refused`
- `bad configuration`

执行：

iptables -L -n
```

如果规则很多，直接清掉测试：

```bash

```
