### 🔧 Key Features

- **High-Resolution Support**: Display images up to 4K resolution, with automatic scaling for smaller display areas.
- **Versatile Image Sources**: Supports common image formats like PNG, JPEG, JPG, and BMP, and can load images from both local files and online URLs.
- **User-Friendly Creation Tool**: Utilize an in-game "magic wand" to select two corners on the same plane, defining the area where the image will be displayed.
- **Efficient Performance**: Employs asynchronous item frame placement, batching 32 frames every 4 ticks to prevent server lag during large image displays.
- **Persistent Displays**: Displays are cached and persist through server restarts and reloads.
- **Simple Management**: Easily remove displays using a dedicated removal mode, eliminating the need to break each item frame manually.
- **Permission Controls**: Manage who can create or remove displays using specific permissions:

  - `imagedisplays.create` – Allows users to create displays.
  - `imagedisplays.remove` – Allows users to remove displays.

   - Enter removal mode by executing:
     ```
     /imagedisplays remove
     ```
