## 更方便的部署方式（二选一）

### A) 简单同步：本地 `public/` 用 rsync 推到 VPS（适合不想在 VPS 上运行 Hexo）
在本地（生成了 `public/` 后）：
```bash
rsync -avz --delete public/ root@your-vps-ip:/var/www/hexo/public/
# 需要 SSH 可免密登录（用 SSH key）
```
优点：直观、快速。

### B) 自动化脚本（在 VPS 上做 pull & generate）
在 VPS `/var/www/hexo/deploy.sh` 写：
```bash
#!/bin/bash
cd /var/www/hexo || exit
git pull origin main
npm install
hexo clean && hexo g
```
给权限：
```bash
chmod +x /var/www/hexo/deploy.sh
```
更新时 SSH 到 VPS 运行：
```bash
cd /var/www/hexo
./deploy.sh
```
或者本地通过 SSH 一行触发：
```bash
ssh root@your-vps-ip "cd /var/www/hexo && ./deploy.sh"
```
