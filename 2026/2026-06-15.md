## 2. 口语怎么备考

B1 口语有三部分：

1. **一起计划事情**  
2. **做一个 3 分钟小演讲**  
3. **听别人讲完后反馈、提问、回答问题**

你不要自由发挥，要准备固定句型。

### 口语 Teil 1：共同计划

万能结构：

> Wir müssen zusammen etwas planen.  
> Ich schlage vor, dass wir ...  
> Wann hast du Zeit?

> Das ist eine gute Idee, aber ...  
> Dann machen wir es so.

你每天练 10 分钟，把这些场景说熟：

这部分不是考创意，是考“能不能协商”。

## 3. 写作怎么备考

官方写作是三题：  
**80 词私人邮件、80 词观点表达、40 词正式/半正式邮件**。fileciteturn0file0

你写作最应该模板化。

### Aufgabe 1：私人邮件

固定结构：

> Liebe/r ...,  
> vielen Dank für deine Nachricht.  
> Meine Feier war sehr schön.  
> Wir haben ...  
> Besonders toll fand ich ..., weil ...  
> Schade, dass du nicht kommen konntest.  
> Vielleicht können wir uns nächste Woche treffen.  
> Hast du am Samstag Zeit?  
> Liebe Grüße  
> ...

每天写一篇，控制在 80 到 100 词。

---

### Aufgabe 2：表达观点

万能结构：

> Ich habe den Beitrag gelesen und finde das Thema sehr interessant.  
> Meiner Meinung nach ...  
> Einerseits ..., andererseits ...  
> In meinem Heimatland ist es oft so, dass ...  
> Ich persönlich finde ..., weil ...  
> Deshalb denke ich, dass ...

这题是提分田。你不需要观点深刻，只要结构清楚、连接词够用。

必须背熟这些词：

> meiner Meinung nach  
> ich denke, dass  
> weil  
> deshalb  
> außerdem  
> zum Beispiel  
> einerseits  
> andererseits  
> im Vergleich zu  
> in meinem Heimatland

---

### Aufgabe 3：正式邮件

固定结构：

> Sehr geehrte Frau Müller,  
> leider kann ich zu unserem Termin nicht kommen.  
> Ich muss ..., weil ...  
> Es tut mir sehr leid.

> Vielen Dank für Ihr Verständnis.  
> Mit freundlichen Grüßen  
> ...

这个只要别乱写，基本能拿分。

## 4. 听力怎么备考

你之前的问题很清楚：**每天新材料，语言不会沉淀。**

所以听力不要刷很多。就用这个模型卷 + Nicos Weg。

方法：

第一遍：正常做题。  
第二遍：看文本听。  
第三遍：一句一句暂停，跟读。  
第四遍：不看文本再听。  
第五遍：把关键词写出来。

听力重点不是“每句都懂”，而是抓：

- 时间
- 地点
- 人物
- 原因
- 转折词：aber, trotzdem, deshalb
- 否定词：nicht, kein, nie
- 建议词：sollen, müssen, könnten

B1 听力经常挖坑：前面说一个，后面转折改掉。你的耳朵要专门抓 **aber**，它像考试里的小地雷探测器。

## 5. 阅读怎么备考

阅读不要逐字翻译。你按题型练。

B1 阅读有五部分，官方模型里包括：判断对错、三选一、广告匹配、观点判断、规则说明理解。fileciteturn0file0

你的做法：

### 阅读顺序

先看题，再回文章找定位词。

不要从头慢慢读。考试不是看小说，是找证据。

### 每天训练

每天做一篇：

1. 先限时做
2. 对答案
3. 把错题对应句子抄出来
4. 标出为什么错

你要建立一个错题表：

| 错因 | 例子 |
|---|---|
| 否定没看见 | nicht, kein |
| 时间看错 | gestern, nächste Woche |
| 人物搞混 | er/sie/Frau Müller |
| 同义替换没识别 | kaufen = bestellen |
| 转折没抓住 | aber, jedoch |

import AVFoundation

final class SpeechManager {
    private let synthesizer = AVSpeechSynthesizer()

    func speakGerman(_ text: String) {
        let utterance = AVSpeechUtterance(string: text)
        utterance.voice = AVSpeechSynthesisVoice(language: "de-DE")
        utterance.rate = 0.45
        utterance.pitchMultiplier = 1.0
        synthesizer.speak(utterance)
    }
}
```

调用：

import SwiftUI

struct WordListView: View {
    @State private var words: [GermanWord] = []
    @State private var searchText = ""
    private let speechManager = SpeechManager()

    var filteredWords: [GermanWord] {
        if searchText.isEmpty {
            return words
        } else {
            return words.filter {
                $0.word.localizedCaseInsensitiveContains(searchText) ||
                $0.zh.localizedCaseInsensitiveContains(searchText)
            }
        }
    }

    var body: some View {
        NavigationView {
            List(filteredWords) { word in
                HStack {
                    VStack(alignment: .leading, spacing: 6) {
                        Text(displayWord(word))
                            .font(.headline)

                        Text(word.zh)
                            .font(.subheadline)
                            .foregroundColor(.secondary)

                        if let phonetic = word.phonetic, !phonetic.isEmpty {
                            Text(phonetic)
                                .font(.caption)
                                .foregroundColor(.secondary)
                        }
                    }

                    Spacer()

                    Button {
                        speechManager.speakGerman(word.word)
                    } label: {
                        Image(systemName: "speaker.wave.2.fill")
                    }
                    .buttonStyle(.borderless)
                }
            }
            .navigationTitle("B1 单词")
            .searchable(text: $searchText, prompt: "搜索德语 / 中文")
            .onAppear {
                words = loadWords()
            }
        }
    }

    private func displayWord(_ word: GermanWord) -> String {
        if let article = word.article, !article.isEmpty {
            return "\(article) \(word.word)"
        }
        return word.word
    }

    private func loadWords() -> [GermanWord] {
        guard let url = Bundle.main.url(forResource: "b1_words", withExtension: "json"),
              let data = try? Data(contentsOf: url),
              let decoded = try? JSONDecoder().decode([GermanWord].self, from: data)
        else {
            return []
        }

        return decoded
    }
}
```
