# 2｜美团和携程对“酒店”的认知不同

| 美团 | 本地即时消费品 | 附近、便宜、评分、可住、优惠券 | 长途行程、品牌故事、旅行规划 | 最大化即时成交率 | 附近搜索 → 比价 → 立刻下单 |
| 携程 | 旅行确定性节点 | 目的地、日期、交通、品牌、售后 | 本地临时需求、低价冲动 | 最大化行程稳定性 + 订单利润 | 目的地规划 → 酒店选择 → 机酒联动 |
| 小红书 | 生活方式展示道具 | 拍照感、审美、氛围、故事、标签 | 实际入住效率、售后 | 最大化种草传播 | 内容种草 → 收藏 → 打卡 |
| 抖音 | 情绪刺激消费场景 | 视觉冲击、低价、反差、剧情 | 深度比较、长期信任 | 最大化停留和冲动转化 | 刷到视频 → 情绪触发 → 团购 |
| 酒店老板 | 可售库存 | 入住率、房价、成本、差评、渠道佣金 | 用户长期身份想象 | 最大化 RevPAR / 利润 | 控房价 → 控渠道 → 控评价 |

这一张表就已经有价值。

因为它告诉你：  
**同一个酒店，在不同系统里不是同一个对象。**

# 3｜“价值函数”怎么设计？

价值函数不是一定要写成数学公式。

它本质是：

> **这个玩家到底在最大化什么。**

模板：

```text
价值函数 = 它最想增加的东西 - 它最想避免的东西
```

比如：

## 美团

```text
价值函数 =
即时成交率
+ 用户复购
+ 平台佣金
+ 本地商家密度
- 用户跳出
- 空页面
- 高售后成本
```

## 携程

```text
价值函数 =
订单客单价
+ 行程完整度
+ 机酒联动
+ 商旅稳定性
+ 品牌信任
- 取消率
- 投诉率
- 库存不确定性
```

## 小红书

```text
价值函数 =
收藏率
+ 分享率
+ 种草强度
+ 审美标签密度
+ 用户停留
- 广告感
- 真实体验崩塌
```

## 抖音

```text
价值函数 =
停留时间
+ 完播率
+ 情绪波动
+ 冲动点击
+ 团购转化
- 用户无感划走
```

展示时可以写成：

```text
玩家：美团
最大化：即时成交
最怕：用户犹豫
所以保留：附近、便宜、可订、评分、优惠
所以忽略：故事、长期规划、高级感
```

这样最清楚。

# 3｜第二步：给每个玩家找“原生信号源”

重点：**不要只看他们说什么，要看他们的界面、排序、字段、价格、规则。**

| 信号源 | 能发现什么 |
|---|---|
| 官网文案 | 它嘴上怎么定义对象 |
| App 界面 | 它实际让用户看什么 |
| 搜索筛选项 | 它认为哪些变量重要 |

# 10｜系统怎么主动“找不同”

核心算法不是复杂 AI，而是 4 个差异检测。

## A. 变量差异

```text id="g84aql"
同一个对象，不同玩家保留的变量不同
```

例：

```text id="fsr45s"
美团重：距离、价格、即时
携程重：日期、行程、品牌
小红书重：审美、打卡、氛围
抖音重：情绪、低价、视觉冲击
```

## B. 价值函数差异

```text id="q78mim"
同一个对象，不同玩家想最大化的东西不同
```

例：

```text id="wkauz9"
美团：即时成交
携程：行程确定
小红书：种草传播
抖音：停留转化
酒店老板：入住率和利润
```

## C. 路径差异

```text id="xzyes3"
同一个对象，不同平台导向的行动不同
```

例：

```text id="pu6pr8"
美团：附近下单
携程：计划旅行
小红书：收藏种草
抖音：冲动团购
```

## D. 失效边界差异

```text id="ejjtxx"
某玩家忽略的变量，可能正是你的机会
```

例：

```text id="n2ufx7"
美团忽略“身份想象”
携程忽略“短视频冲动”
小红书忽略“交易闭环”
抖音忽略“长期信任”
```

你的机会往往在：

```text id="cxwhn9"
A 玩家忽略的变量
+
B 玩家证明过的需求
+
你能低成本重组的路径
```

```text id="12kwth"

- 商家规则
- 用户讨论
- 价格和成交入口

4. 它忽略了哪些变量？
```

# 13｜真正的系统核心

你要找不同，不是靠“多问几个 AI”。

而是靠这个机制：

```text id="v2k4aa"
同一对象
进入不同玩家的系统
被不同字段描述
被不同规则排序
被不同目标函数奖励
被不同交易路径验证
最后产生不同现实结果
```

所以系统要抓的不是观点本身，而是：

```text id="ng5pos"
字段
排序
入口
价格
转化
规则
评价
资金
行为
```

这些才是“表征”的影子。

最终压缩一句：

> **不同表征不是从嘴里找出来的，是从玩家的界面、规则、排序、交易和行为里反推出来的。**
