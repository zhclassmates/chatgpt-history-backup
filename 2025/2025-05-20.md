## ✅ 场景说明

你希望呈现两个来源（比如《高岛易断》与《周易原文》）关于某一个卦象的内容对照解读，可能包括：

- 原文（传统文本）
- 注解 / 解说
- 出处区分（左边一本书，右边另一本）
- 支持移动端和网页端阅读
- 支持 AI 生成的解释（扩展）

## 🖼️ 推荐排版方式

### 方式一：**左右对照（双栏对比）**

```html
<div class="compare-container">
  <div class="column book1">
    <h3>《高岛易断》</h3>
    <p><strong>卦象解：</strong>乾为天，阳刚纯粹，为诸卦之首……</p>
    <p><strong>爻辞解：</strong>初九，潜龙勿用。象曰：阳在下也……</p>
  </div>
  <div class="column book2">
    <h3>《周易原文》</h3>
    <p><strong>卦象原文：</strong>乾：元，亨，利，贞。</p>
    <p><strong>象传：</strong>天行健，君子以自强不息。</p>
  </div>
</div>
```

```css
.compare-container {

```

### 方式二：**折叠式切换（单栏 + Tab）**

移动端体验更好，使用按钮切换两个来源内容：

```html
<div class="tab-buttons">
  <button onclick="showTab('book1')">高岛易断</button>
  <button onclick="showTab('book2')">周易原文</button>
</div>

<div id="book1" class="tab-content">
  <h3>《高岛易断》</h3>
  <p>……内容……</p>
</div>
<div id="book2" class="tab-content" style="display:none;">
  <h3>《周易原文》</h3>
  <p>……内容……</p>
</div>
```

#### 简单 JS 控制切换：

```javascript
function showTab(id) {
  document.querySelectorAll('.tab-content').forEach(el => el.style.display = 'none');
  document.getElementById(id).style.display = 'block';
}
```

#### 1. **开发速度优先，不求完美**

#### 2. **AI要成为节目“角色”**
你可以像“与AI吵架”“AI误解我的意思”“AI教我做错的事情”这样处理内容，增加趣味性。

#### 3. **用户互动做得巧妙**
- 视频结尾附带试玩链接（H5 或小程序）
- 鼓励观众二创（如：谁能把这个App用得最认真？）
- 做“观众投稿脑洞我来做”环节，形成社区内容

### 🎥 拍摄与风格建议：

- 拍摄风格可以类比“手工耿”+“谷阿莫”+“程序员自黑”
- 可自称“AI喂饭开发者”“废App炼金术士”“无用系程序员”
- 表达方式搞怪冷面+字幕辅助吐槽效果更佳
- 视频时长控制在1-3分钟，适合B站、小红书、抖音等平台

### 📈 长期玩法与变现可能：

- 可考虑出“脑洞APP图鉴”“App设计卡牌”“无用工具盲盒”等周边
