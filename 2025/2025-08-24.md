* 使用绝对路径，不用 `~`：

  ```bash

  ```

* 确认 `www.youtube.com_cookies.txt` 文件确实存在这个位置：


### AI

很好的问题 👍  

`yt-dlp` 默认会优先下载 **最佳画质**，而 YouTube 上的最佳画质通常是 **WebM (VP9/AV1 视频 + Opus 音频)**，所以你才会得到 `.webm` 文件。  

要转成 MP4，有两种方式：

---

## 方式一：直接用 `yt-dlp` 输出 MP4  
在下载时就指定转码（推荐 ✅）：  

```bash
yt-dlp \
--cookies "/Volumes/01_hard/youtube/www.youtube.com_cookies.txt" \
-f "bv+ba" \
--merge-output-format mp4 \
-o "/Volumes/01_hard/youtube/%(title)s.%(ext)s" \
"https://youtu.be/3cq6cLguW3A"
```

### 参数解释：
- `-f "bv+ba"` 👉 下载最佳视频（bv）+最佳音频（ba）。  
- `--merge-output-format mp4` 👉 下载完成后合并并转为 mp4。  
- `-o ...` 👉 指定输出路径。  

这样下载出来的就是 `.mp4` 文件了。  

---

## 方式二：已有 `.webm` 转成 `.mp4`（用 ffmpeg）
如果你已经下好 `.webm` 文件，可以用 `ffmpeg` 转码：  

```bash
ffmpeg -i input.webm -c copy output.mp4
```

⚡ 说明：  
- `-c copy` 👉 直接封装（无损转换，速度极快）。  
- 但是注意：如果视频是 **AV1/VP9 编码**，有些旧播放器（比如 Windows 的默认播放器）可能不支持，即使转成 MP4 容器也无法播放。  
- 如果想确保兼容性（例如电视、旧手机），可以转成 H.264：  

```bash
ffmpeg -i input.webm -c:v libx264 -c:a aac output.mp4
```

这样会重新编码，体积大一些，但几乎所有设备都能播。  

---

👉 建议：如果以后你希望 **直接得到 mp4**，最好用 **方式一**，让 `yt-dlp` 下载后自动转。
