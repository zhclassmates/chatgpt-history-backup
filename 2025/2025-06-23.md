#### 一分钟快速上手

1. **下载安装**：访问 Cursor 官网 → Download。  
2. **导入项目**：首次启动会提示打开本地或远端 Git 仓库。  
3. **激活试用**：登录后即自动开始 14 天 Pro 试用；设置里可查看剩余天数与请求用量。  
4. **善用 Normal / Max 切换**：  
   - 日常写代码、改函数 → Normal（省配额）。  
   - 大型重构、跨项目检索、让 Agent 全自动修 Bug → Max。  
5. **试用到期**：如果暂不续费，可继续免费 Hobby；需要更高额度时再升级即可。

#### 可能遇到的三个常见疑问

| 问题 | 答案 |
|------|------|
| **试用期加速耗完怎么办？** | 打开 *Settings → Usage & Billing*，启用按量计费（每额外请求 \$0.04 起）；也可等次月配额刷新。 |
| **能否绑定自己 OpenAI API Key？** | 可以，但 Tab 补全、Apply from Chat 等自研模型依旧走 Cursor 额度，API Key 仅替换对话模型调用。 |
| **和 GitHub Copilot 有何差别？** | Cursor 基于 VS Code 分支，内置整项目搜索与类 ChatGPT 面板，Agent 能自动跨文件修改；Copilot 侧重行级补全。重度重构 / 调错时 Cursor 优势更大。 |
