## 一句话本质
**HyperFrames = 用 HTML 写视频，然后自动渲染成 MP4 的开源框架。**

它把“做视频”这件事，从剪辑软件（时间轴+鼠标） → 变成“写代码（HTML/CSS/JS）”。citeturn0search1turn0search5  


---

## 核心设计（为什么它不一样）

### 1）视频 = 网页
你不是在 PR、AE 里拖素材，而是写类似这样的东西：

```html
<h1 data-start="1" data-duration="4">Hello</h1>
<video src="intro.mp4"></video>
<audio src="bgm.wav"></audio>
```

然后：

```bash
npx hyperframes render
```

➡️ 直接生成视频。citeturn0search6  


👉 本质变化：
- 传统视频 = timeline + GUI  
- HyperFrames = **声明式结构 + 可编程**

---

### 2）专门为 AI Agent 设计
这个项目不是给人手点鼠标用的，是给 AI 写视频用的：

- AI 输出 HTML  
- HyperFrames 负责渲染视频  
- 整个流程可自动化  

👉 等于：
**AI = 导演 + 编剧 + 动效师**  

这是它最核心的定位。citeturn0search1  


---

### 3）确定性渲染（很关键）
同一份代码 → 永远生成完全一样的视频

👉 没有：
- 掉帧  
- 时间漂移  
- 随机动画差异  

适合：
- 批量生成
- 自动化 pipeline
- CI/CD 视频（像 build 一样） citeturn0search5  


---

### 4）技术栈（你关心的底层）
不是黑盒，完全工程化：

- 渲染：Puppeteer（浏览器）  
- 编码：FFmpeg  
- 动画：CSS / GSAP / Lottie / Three.js  
- CLI：Node.js  

👉 结构：
- core（解析）
- engine（渲染）
- producer（合成） citeturn0search5turn0search10
