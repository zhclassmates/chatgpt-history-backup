## 1️⃣ 中文搜索的技术核心
中文搜索和英文搜索不一样，主要难点在于 **分词** 和 **相关性排序**。  

### （1）分词（Tokenization）
- 中文没有空格分隔，所以必须先进行 **中文分词**。  
- 开源工具：
  - **jieba**（简单易用，Python常用）
  - **HanLP**（支持深度学习模型，效果更好）
  - **THULAC**（清华出品，速度快）
- 举例：
  ```python
  import jieba
  text = "我想建一个中文搜索引擎"
  print(list(jieba.cut(text)))
  # ['我', '想', '建', '一个', '中文', '搜索引擎']
  ```

### （2）索引（Inverted Index）
- 把所有文档（文章、网页、资料）分词，然后建立 **倒排索引**：
  - 记录“某个词出现在哪些文档中，位置是多少”
- 常用方案：
  - **Elasticsearch / OpenSearch**（最成熟的企业级搜索引擎，支持中文分词插件）
  - **Whoosh**（纯 Python，轻量）
  - **Solr**（基于 Lucene）

### （3）检索与排序
- 搜索时，把用户的查询分词，查索引，返回相关文档。
- 排序算法：
  - **TF-IDF**（传统方式）
  - **BM25**（Elasticsearch 默认，效果好）
  - **Embedding 语义搜索**（用 BERT、ERNIE 等中文模型，把语义相近的内容找出来）

# 🔑 主流开源中文搜索解决方案（适合千万级文档）

## 1️⃣ Elasticsearch + IK 分词 / jieba 分词  
- **架构**：基于 **Lucene**，分布式，成熟度最高。  
- **优势**：
  - 超大规模文本（上亿级）都能搞定  
  - 插件丰富（IK Analyzer、jieba、HanLP 都能集成）  
  - 自带 **BM25 排序**  
  - 有 Kibana 管理界面  
- **缺点**：资源占用较高，至少需要 2–3 台服务器才比较稳  
- **应用案例**：百度云搜索、知乎内部检索  

👉 适合你现在的量级（200万–1000万），未来能扩展  

---

## 2️⃣ OpenSearch (原阿里开源，基于 Elasticsearch)  
- **架构**：Elasticsearch 分支，完全兼容  
- **优势**：
  - 社区活跃度越来越高  
  - 支持中文分词，带现成的 **智能检索**  
  - 和 Elastic 商业化分离，开源协议更宽松  
- **缺点**：生态比 Elasticsearch 小  
- **应用案例**：阿里系搜索业务  

👉 如果担心 Elasticsearch 的商业限制，可以直接用 OpenSearch  

---

## 3️⃣ Solr + HanLP 分词  
- **架构**：同样基于 **Lucene**  
- **优势**：
  - 稳定性非常强  
  - 对 XML/结构化数据支持好  
- **缺点**：相比 Elasticsearch，社区和文档少，扩展生态不如 ES  
- **应用案例**：维基百科、政府数据检索  

👉 如果你更看重 **稳定性** 而不是生态，可以考虑  

---

## 4️⃣ Vespa (Yahoo 开源的搜索引擎)  
- **特点**：
  - 天生支持 **大规模向量检索**（语义搜索）  
  - 能同时做传统关键词搜索 + 深度学习 embedding 检索  
- **缺点**：国内中文社区少，上手难度高  
- **应用案例**：Yahoo、Spotify、华为内部语义检索  

👉 如果未来要做 **语义搜索/智能推荐**，可以考虑

## `meili/import.py`（启动后你可进容器执行，也可本机执行）
```python
import json, os, requests, sys

MEILI = os.getenv("MEILI_HOST", "http://localhost:7700")
KEY = os.getenv("MEILI_API_KEY", "change_this_master_key_very_strong")
INDEX = "docs"

def ensure_index():
    url = f"{MEILI}/indexes/{INDEX}"
    r = requests.get(url, headers={"Authorization": f"Bearer {KEY}"})
    if r.status_code == 200:
        return
    payload = {"uid": INDEX, "primaryKey": "id"}
    r = requests.post(f"{MEILI}/indexes", json=payload, headers={"Authorization": f"Bearer {KEY}"})
    r.raise_for_status()

    # 设置中文友好的属性
    settings = {
        "searchableAttributes": ["title", "content", "tags"],
        "displayedAttributes": ["id", "title", "content", "url", "tags", "published_at", "_snippetResult", "_formatted"],
        "filterableAttributes": ["tags","published_at"],
        "sortableAttributes": ["published_at"],
        "typoTolerance": {"enabled": True}
    }
    requests.patch(f"{MEILI}/indexes/{INDEX}/settings",
                   json=settings, headers={"Authorization": f"Bearer {KEY}"}).raise_for_status()

    # 同义词（可选）
    try:
        with open("/data/synonyms.json","r",encoding="utf-8") as f:
            syn = json.load(f)
        requests.put(f"{MEILI}/indexes/{INDEX}/settings/synonyms",
                     json=syn, headers={"Authorization": f"Bearer {KEY}"}).raise_for_status()
    except Exception:
        pass

def import_jsonl(path):
    docs = []
    with open(path,"r",encoding="utf-8") as f:
        for line in f:
            if line.strip():
                docs.append(json.loads(line))
    # 分批写入
    headers = {"Authorization": f"Bearer {KEY}"}
    batch = 5000
    for i in range(0, len(docs), batch):
        chunk = docs[i:i+batch]
        r = requests.post(f"{MEILI}/indexes/{INDEX}/documents", json=chunk, headers=headers)
        r.raise_for_status()
        print("task:", r.json())

if __name__ == "__main__":
    ensure_index()
    path = sys.argv[1] if len(sys.argv) > 1 else "/data/sample.jsonl"
    import_jsonl(path)
    print("import done")
```

> 你的 500 万“字”即使是几十万条记录，Meilisearch 单机也轻松吃下。真实数据请转成 jsonl 后导入。

## `api/main.py`
```python
import os, httpx
from fastapi import FastAPI, Header, HTTPException
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel

MEILI_HOST = os.getenv("MEILI_HOST", "http://meilisearch:7700")
MEILI_KEY  = os.getenv("MEILI_API_KEY")
API_PUBLIC = os.getenv("API_PUBLIC_KEY")
API_MEMBER = os.getenv("API_MEMBER_KEY")
INDEX = "docs"

origins = [o.strip() for o in os.getenv("CORS_ORIGINS","").split(",") if o.strip()]

app = FastAPI(title="CN Search API")

app.add_middleware(
    CORSMiddleware,
    allow_origins=origins or ["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

class SearchIn(BaseModel):
    q: str
    page: int = 1
    limit: int = 10
    tags: list[str] | None = None

def guard(x_api_key: str | None) -> str:
    # 简易会员：带 member key 的用户可拿更多结果
    if x_api_key == API_MEMBER:
        return "member"
    if x_api_key == API_PUBLIC:
        return "public"
    # 可按需改为匿名也能查：这里默认必须带 key，保证不上公网被刷
    raise HTTPException(401, "invalid api key")

@app.get("/health")
def health():
    return {"ok": True}

@app.post("/search")
async def search(payload: SearchIn, x_api_key: str | None = Header(default=None)):
    role = guard(x_api_key)
    limit = min(max(payload.limit, 1), 50 if role=="member" else 10)
    page = max(payload.page, 1)
    offset = (page-1)*limit

    meili_body = {
        "q": payload.q,
        "limit": limit,
        "offset": offset,
        "highlightPreTag": "<em>",
        "highlightPostTag": "</em>",
        "attributesToHighlight": ["title","content"],
        "attributesToCrop": ["content"],
        "cropLength": 120,
        "filter": []
    }
    if payload.tags:
        meili_body["filter"].append([" OR ".join([f'tags = "{t}"' for t in payload.tags])])

    async with httpx.AsyncClient(timeout=15.0) as client:
        r = await client.post(f"{MEILI_HOST}/indexes/{INDEX}/search",
                              headers={"Authorization": f"Bearer {MEILI_KEY}"},
                              json=meili_body)
        r.raise_for_status()
        data = r.json()

    # 对外响应：可在此插广告位（第 1/4/8 条）
    hits = data.get("hits", [])
    result = []
    for i, h in enumerate(hits, start=1):
        item = {
            "id": h.get("id"),
            "title": h.get("_formatted",{}).get("title") or h.get("title"),
            "snippet": h.get("_formatted",{}).get("content") or h.get("content","")[:160],
            "url": h.get("url"),
            "tags": h.get("tags"),
            "published_at": h.get("published_at")
        }
        # 简单广告占位（前端可根据 type 渲染）
        if i in (1,4,8):
            result.append({"type":"ad","slot": f"search_inline_{i}"})
        result.append({"type":"doc", **item})

    return {
        "page": page,
        "limit": limit,
        "total": data.get("estimatedTotalHits", 0),
        "items": result
    }
```

import { useEffect, useMemo, useState } from "react";

export default function Home() {
  const API = process.env.NEXT_PUBLIC_API_BASE || "http://localhost:8080/api";
  const [q, setQ] = useState("");
  const [items, setItems] = useState<any[]>([]);
  const [total, setTotal] = useState(0);
  const [page, setPage] = useState(1);

      method: "POST",
      headers,

    setItems(data.items || []);
    setTotal(data.total || 0);
    setPage(data.page || 1);
    setLoading(false);

      <div style={{display:"flex", gap: 8}}>
        <input
          value={q}
          onChange={e=>setQ(e.target.value)}
          onKeyDown={e=>e.key==="Enter" && search(1)}
          placeholder="输入关键词，例如：光伏 出口"
          style={{flex:1, padding: 12, fontSize: 16}}
        />
        <button onClick={()=>search(1)} disabled={loading} style={{padding:"12px 16px"}}>
          {loading ? "搜索中..." : "搜索"}
        </button>
      </div>

      <div style={{marginTop: 16, color:"#666"}}>共 {total} 条</div>

      <ul style={{listStyle:"none", padding:0, marginTop: 16}}>
        {items.map((it, idx) => {
          if (it.type === "ad") {
            // 预留广告占位（替换为你的 Adsense/联盟代码）
            return <li key={`ad-${idx}`} style={{padding:"12px 8px", background:"#fafafa", border:"1px dashed #ccc", margin:"16px 0"}}>
              <div>【广告位】{it.slot}</div>
            </li>;
          }
          const title = it.title || "";
          const snippet = it.snippet || "";
          return (
            <li key={it.id} style={{padding:"12px 8px", borderBottom:"1px solid #eee"}}>
              <a href={it.url || "#"} target="_blank" rel="noreferrer"
                 dangerouslySetInnerHTML={{__html: title}} />
              <div dangerouslySetInnerHTML={{__html: snippet}} style={{color:"#444", marginTop:6}} />
              {it.tags?.length ? <div style={{fontSize:12, color:"#999"}}>标签：{it.tags.join(" / ")}</div> : null}
            </li>
          );
        })}
      </ul>

      {total > 10 &&
        <div style={{display:"flex", gap:8, marginTop:16}}>
          <button disabled={page<=1} onClick={()=>search(page-1)}>上一页</button>
          <button onClick={()=>search(page+1)}>下一页</button>
        </div>
      }
    </main>
  );
}

# 7) 生产要点（最小安全 & 运营）

- **API Key 管理**：前端放的是“游客 key”，正式上线请：
  - 用后端会话 / 服务端渲染隐藏 key，或给公开查询走“匿名”限流网关

- **限流**：Caddy/Cloudflare 开基本防护；后端可加简单的 IP 限流（如 Nginx/Caddy rate-limit 或在 API 内计数）  
- **备份**：`meili_data` 是数据卷，定期打包或挂对象存储  
- **监控**：Caddy/Meili 都很轻，可先观察 VPS 资源；访问大了再上 Prometheus/Grafana  
- **广告**：把前端“广告位”替换为你的广告脚本（Adsense/联盟）  
- **会员**：给登录页与后台另立一套（本方案已预留“会员 key”分级能力）

## 1️⃣ 去中心化网站的基本原理

去中心化网站通常 **不依赖单一服务器**，而是把内容存储和访问分布在全网节点上，常用技术包括：

| 技术 | 原理 | 代表项目 |
|------|------|---------|
| **IPFS（InterPlanetary File System）** | 文件分布式存储，内容通过哈希标识，不依赖单一服务器 | [ipfs.io](https://ipfs.io) |
| **Arweave** | 永久存储，数据一次上传永久存储，节点奖励存储 | [arweave.org](https://www.arweave.org) |
| **Filecoin / Storj** | 类似云存储，但付费存储在去中心化网络上 | [filecoin.io](https://filecoin.io) |

特点：
- 数据通过 **内容哈希** 唯一标识  
- 用户访问时从最近或最优节点拉取数据  
- 不依赖单一服务器，因此不容易被封锁或掉线

- **会员系统 / 广告 / API**：需要动态服务逻辑，这部分仍需服务器支持  
- **大数据量更新**：Arweave 适合一次上传永久存储，不适合频繁修改  
- **搜索性能**：从 IPFS 节点拉取大数据延迟高，不适合高频实时查询  

### 适合用途
- **存储静态内容、备份全文库**
