### 一、需要测量的信号特征（目标信号）

**1. 物理本质**
- **类型**：三轴加速度（**非姿态角**、非角度），测量局部组织的**微机械振动**
- **方向特征**：Z轴（垂直皮肤方向）振幅显著大于X/Y轴（用于区分局部肌肉收缩 vs 全身运动）

**2. 信号参数（量化指标）**
| 参数 | 数值范围 | 临床意义 |
|------|---------|---------|
| **幅度** | **0.01g – 0.2g**（10 mg – 200 mg） | 静息期 0.01g，高潮期峰值 0.05-0.1g |
| **主频** | **0.8 – 1.5 Hz**（每分钟 48-90 次） | 盆底肌节律性收缩频率，区别于步行（1.2-2 Hz） |
| **波形** | 近似正弦/三角波 | 肌肉收缩-放松的周期性包络 |
| **持续时间** | 连续 **5-15 秒** 的周期性峰值 | 有效收缩事件（<3秒为无效触发） |
| **频谱集中度** | 0.8-1.5 Hz 能量占比 **>40%** | 高潮/有效收缩的判定阈值 |

**3. 关键干扰信号（需过滤）**
- **步行伪迹**：1.2-2 Hz，但振幅 **>0.3g** 且三轴同相（整体移动）
- **呼吸伪迹**：0.2-0.4 Hz，规律性波动
- **运动伪迹**：全身运动通常 **>0.5g**，可作为触发冻结的阈值

### 二、传感器选择标准（必要 vs 优选）

#### ■ 必要条件（不满足则无法检测）
| 指标 | 最低要求 | 推荐值 | 原理说明 |

| **采样率** | ≥50 Hz（奈奎斯特） | **100-200 Hz** | 保留0.8-1.5 Hz信号，同时避免混叠 |
| **带宽** | 0.5-50 Hz | 带通滤波 | 高通0.5Hz滤除漂移，低通50Hz抗混叠 |

| **无线接口** | BLE 5.0，**原始数据广播** | 支持Notify/Indicate输出原始加速度，非仅姿态角 |

### 四、选型避坑指南（关键风险）

**1. 量程陷阱（最常见）**
- **绝对避免**：WT901、JY62、MPU6050等**默认±16g且不可配置**的模组
- **后果**：有效分辨率仅4-8 mg，0.01g信号完全淹没在量化噪声中
- **验证**：采购前确认寄存器`CTRL1`可写入`FS_MODE=00`（±2g模式）

**2. 分辨率虚标**
- **警惕**：部分蓝牙模组为降低传输负载，**内部降采样至8位**输出（分辨率仅8 mg）
- **要求**：必须支持**16位原始数据**直接输出（或至少12位以上有效位）

**3. 功耗陷阱**
- **避免**：NRF51822+LIS3DH组合（功耗>200μA，续航<1周）
- **要求**：传感器本身工作电流**<20μA**，配合BLE休眠实现整体<100μA

**4. 固件锁定**
- **风险**：某些成品模组固化为"姿态传感器"固件，**仅输出欧拉角**，不输出原始加速度
- **要求**：必须支持**原始三轴加速度数据**广播（Raw Data Notify）

### 2. Analog Devices ADXL354：量产化的“精密之魂”

- **审核评价：** 它是高性能与微型化的平衡点。
- **核心优势：** 它的噪声密度虽然略高于 SDI，但其输出的**比例稳定性（Ratiometric）**极佳。这意味着当电池电压微弱波动时，信号不会随之产生假跳变。

## 一、参数推导的逻辑溯源

### 1. 「10-200 mg」幅度来源
**推理路径：**
```
已知基准：手指轻触桌面产生的振动 ≈ 50-100 mg (可实测)
生物类比：盆底肌慢肌纤维收缩力 ≈ 手指轻触力的 1/5 - 1/10
（盆底肌单纤维收缩力 10-50 mN，手指屈肌单纤维 100-500 mN）

```

**可疑点**：这是肌肉力到机械振动的转换，忽略了组织阻尼。实际体表振幅可能只有内部的 **1/10 - 1/50**。

### 2. 「2-20 Hz」频率来源
**推理路径：**
```
肌电信号 (EMG) 频谱：盆底肌表面肌电主导频率 10-80 Hz

→ 推断机械频带：2-25 Hz，有效信息集中在 8-15 Hz（类心率变异性频段）
```

**支撑文献**：Levator ani 肌的超声弹性成像研究显示其机械响应在 5-12 Hz 范围。

奈奎斯特：20 Hz × 2 = 40 Hz（理论最低）

大量综述/章节也反复提到：前几次收缩常见 **约 0.8s 间隔**，后面可能拉长。citeturn0search12turn0search19turn0search0

### 3) sEMG 能不能当事件源

## 1) 必须有：局部节律收缩事件指标（你的主胜负手）

- **序列密度**：`N_peaks / T_seq`

### B. 幅度包络（“先增强后衰减”）
- **峰幅度 A_peak 的包络形态**：
  - `slope_first_half(A_peak) > 0` 且 `slope_last_half(A_peak) < 0`

- **峰幅度动态范围**：`max(A_peak)/median(A_peak)`（太平=不像事件，太夸张=可能体动）

  - **宽带功率**：`P(0.5–30 Hz)`  
  - **节律占比**：`P_rhythm / P_wide`（越高越像“有组织的收缩”）

## 1) 硬件与佩戴方案（组合1+2合并版）

### 必选（最低可用）
1) **胸带 ECG（心电）**

3) **会阴/骨盆底表面 EMG（智能内裤电极或贴片）**

## 2) 实时信号处理链路（必须照这个顺序，不然会被伪影打爆）

### ECG → HR/HRV
- 带通：0.5–40 Hz
- R峰检测 → RR间期
- 输出特征（每 1s 更新，窗口 10–30s）：
  - HR 当前值、HR 上升斜率 dHR/dt
  - RMSSD / SDNN（别太执着，趋势更重要）
  - 信号质量 SQI（R峰置信度、丢峰率）

### IMU → 运动上下文 + 伪影门控
- 特征（每 1s 更新，窗口 2–5s）：
  - accel_rms、gyro_rms
  - 周期性强度（自相关峰值）
  - “剧烈运动段”标记：motion_high = accel_rms > Tm

### EMG → 收缩“串”检测（你的硬触发发动机）
- 预处理：
  - 带通：**20–450 Hz**
  - 工频陷波：50/60 Hz（看地区）
  - 全波整流 + 包络（低通 3–10 Hz）
- 事件检测：
  - 先找 burst（包络超过阈值的片段）
  - 再看 burst 的节律：是否出现 **4–12 次**近似等间隔 burst
  - 节律频率范围：建议先放宽 **0.6–2.5 Hz**（不要写死）
- 质量控制：
  - 电极接触差、滑移会让包络“塌陷或乱跳”，要给 EMG 一个 SQI

### EDA（可选）
- 分离 tonic/phasic（简单点：移动中位数当 tonic，剩下当 phasic）
- 看 phasic 峰密度/峰幅在高潮候选窗内是否显著上升

## 3) 判定逻辑：状态机 + 多证据融合（最能落地的做法）

### 状态机（强烈建议）
- **S0 baseline**
- **S1 arousal**：HR 持续上升 + motion 有节律
- **S2 plateau**：HR 高位相对稳定 + EDA/呼吸高位（可选）
- **S3 climax_candidate**：EMG 出现节律 burst 串
- **S4 recovery**：HR 回落 + EMG 串结束

### 关键：硬触发 + 软门控
**硬触发（必须满足）**
- EMG 检测到节律 burst 串（满足 burst_count、间隔稳定性、持续时长）

**软门控（建议满足 2/3）**
- HR 在过去 30–90s 有显著上升，或处于高位
- EDA phasic 在候选窗内有峰（可选）
- IMU 表明不是“单纯滑移/撞击伪影”（motion_high 时要求 EMG 节律更稳定、更强）

### 一个可直接实现的评分（示意）
- score = 0
- score += 0.6 * EMG_rhythm_conf
- score += 0.2 * HR_trend_conf
- score += 0.1 * EDA_conf（可选）
- score += 0.1 * context_conf（IMU节律一致性）
- 当 **EMG_rhythm_conf > 0.75 且 score > 0.8** → 触发 climax_detected  
- 触发后进入 **refractory（不应期）** 2–5 分钟内降低再次触发敏感度，防止连发误报

## 4) 校准策略（不校准必翻车）

1) **静态基线 2 分钟**

- EMG 噪声地板 + 接触质量

2) **个体阈值学习（每次自动微调）**

- motion_high 阈值按用户动作幅度自适应（分位数法，比如 90th percentile）

## 5) 误报的前三大来源（提前堵住）
1) **EMG 电极滑移/接触变差** → 假 burst 或包络乱跳  
   - 解法：EMG_SQI 低时禁止硬触发，只给“低置信候选”

2) **剧烈运动冲击** → IMU 巨峰同时污染 EMG/ECG  
   - 解法：motion_high 时提高 EMG 节律要求（更严格的间隔一致性 + 更高幅度）

3) **心率上升但非高潮**（运动、情绪）  
   - 解法：HR 只能当软证据，永远别当唯一触发

法规/平台规则一变，自动推演你业务哪些环节会被击穿，并给补丁方案。人类通常等出事才补。

10) **需求反向生成器（Inverse Requirement Engine）**  
你只说“我不想要什么/我怕什么/我不能踩什么”，AI反推出最可行的产品形态。人类常被“想要”误导。

11) **心理负载温度计（Cognitive Load Thermometer）**  
从你的操作路径、停顿、撤销、回退、犹豫次数推断“哪里让人累”，自动改UI。人类问卷很假，行为数据很真。

12) **群体注意力地震仪（Attention Seismograph）**  
在你看不见的角落，某个话题开始微震，AI提前 24–72 小时预测它会不会爆。人类只能追热点，AI能追“前震”。

13) **自我对抗测评官（Adversarial QA）**  
你上线前，AI用“坏人视角/骗子视角/杠精视角/律师视角”连续攻击你的产品并打分。人类做不了这么稳定的多人格红队。

14) **能量最小化架构师（Energy-Minimizing Architect）**  
给定目标，AI找“最省人力/最少步骤/最少维护”的实现，不追求完美功能。人类工程师容易堆技术债。

15) **行为指纹去噪器（Behavioral De-noiser）**  
把“人类行为里的随机性”滤掉，只留可预测结构，用于事件检测/健康监测。人脑看到噪声就想编故事。

16) **时间线法医（Timeline Forensics）**  
当你只给它一堆截图、片段、聊天记录，AI能还原“真实发生顺序”和关键缺口。人类在碎片里非常容易错判因果。

17) **多目标妥协求解器（Pareto Bargainer）**  
你要同时满足隐私、体验、成本、准确率、续航、合规，AI能给出 Pareto 前沿方案。人类常靠拍脑袋选一个极端。

18) **不可见协作导演（Invisible Collaboration Director）**  
在团队协作中，AI自动把任务切成“互不阻塞的并行块”，减少等待。人类经常把所有人卡在同一条线上。

19) **情境化记忆压缩器（Context Compressor）**  
把一个复杂项目压缩成“可继续工作的最小状态向量”（目标、约束、未决、风险），每次开工秒进入状态。人类靠热身，AI靠状态恢复。

20) **现实世界的“软测量”引擎（Soft-Sensing Engine）**  
你测不到的指标，用多个可测信号推断出来（如疲劳、压力、恢复、峰值事件）。人类不擅长做鲁棒的多信号融合。
