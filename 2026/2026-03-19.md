🛠️ 核心架构：离线“森林贸易”AI 系统
整个系统分为四个核心模块，全部跑在你那部 16GB 内存的手机里。
1. 语言大脑 (LLM Core)
 * 推荐模型： Qwen-2.5-7B-Instruct-GGUF (4-bit 量化版)。
 * 理由： 7B 参数是 16GB 内存的“天花板”平衡点，逻辑极强，能处理复杂的压价、谈判逻辑。
 * 功能： 负责中老翻译、贸易决策、逻辑推理。
2. 语音器官 (Speech System)
 * 听（ASR）： Faster-Whisper (Tiny 或 Base 离线模型)。
   * 特点： 极速，抗噪能力强，适合森林环境。
 * 说（TTS）： Piper 或 Sherpa-ONNX。
   * 特点： 纯离线，支持导出 .onnx 格式，声音自然，不吃 CPU。
3. 视觉眼睛 (Vision System)
 * 推荐模型： Moondream2 (只有 1.6B 参数)。
 * 功能： 识别蜂蜜颜色、橡胶干度，并把图像特征转成文字喂给“大脑”。
4. 运行载体 (Inference Engine)
 * 推荐工具： MLC-LLM 或 llama.cpp (Android 版)。
 * 理由： 它们能直接调用安卓手机的 GPU/NPU 加速，确保翻译不卡顿，手机不烫手。

- 简短、直接、实用

- 每一句都能在现实中用
