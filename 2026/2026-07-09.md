## 最稳方案

### 方案 A：让对方直接发“音频文件”

这是最干净的。

你把句子发给对方：

> Bitte lies diesen Satz langsam und natürlich vor.  
> Ich möchte eine Ausbildung als Elektroniker machen.

让他不要用微信“按住说话”，而是：

- iPhone 用“语音备忘录”录
- 导出为 m4a
- 微信发“文件”
- 你保存下来

这样得到的是标准音频文件，后面可以直接放进你的系统。

这是最推荐的路线。

## 如果已经是微信语音怎么办？

微信语音消息本身是“聊天消息”，不是普通 mp3 文件。微信支持语音消息，PC/Web 端也需要手机扫码登录使用。citeturn743114search1 但微信官方没有把每条语音直接导出成 mp3 的顺滑入口。

所以你有三种路：

## 1. 录屏 / 录系统声音

最现实。

### iPhone 上

播放微信语音，同时用：

- iOS 录屏
- 或另一台设备录音

然后把视频/音频导出，转成 mp3/m4a。

缺点：音质一般。  
优点：最简单，不折腾微信内部文件。

## 2. 电脑端播放，再录系统声音

这个更适合你做材料库。

### Windows

用：

- 微信电脑版播放语音
- Audacity 录制系统声音
- 导出 wav / mp3

### Mac

用：

- 微信 Mac 版播放语音
- OBS / QuickTime + 虚拟声卡 BlackHole
- 导出音频

这条路更适合批量做。

## 3. 抓微信本地语音文件

技术上有人做过，但我不建议你走这条。

原因：

- iPhone 沙盒限制强
- 微信本地文件路径和格式经常变
- 可能涉及聊天数据库、加密、第三方工具
- 2026 年还出现过腾讯针对第三方微信聊天记录导出工具的下架/投诉事件，说明这条路不稳定也有合规风险。citeturn850079search1

所以你的学习工具别依赖“破解微信语音文件”。这条路像在沼泽里铺铁轨，越铺越陷。

# 你真正应该做的结构

你的素材库应该这样建：

```text
sentence_id: 0001
text: Ich möchte eine Ausbildung als Elektroniker machen.
source: 微信真人录音 / Nicos Weg / TTS / 自己录音
speaker: 德国人 / 老师 / 自己 / TTS
level: A1-A2
audio_file: 0001_native_male_01.m4a
transcript: Ich möchte eine Ausbildung als Elektroniker machen.
note: 自然语速，重音在 Ausbildung / Elektroniker
```

然后每个句子可以挂多个音频：

```text
0001_tts_edge_de-DE.mp3
0001_native_wechat_01.m4a
0001_my_recording_20260709.m4a
```

这样你就有三层对比：

| 音频 | 用途 |
|---|---|
| TTS | 稳定基准 |
| 真人微信音频 | 自然语流 |
| 自己录音 | 对比纠音 |

# 关键提醒

微信真人语音适合做：

- 句子节奏样本
- 真人语调样本
- 口语自然连贯样本
- 你的模仿对象

但不一定适合做：

- 绝对标准发音
- 音素级标准库
- 考试发音评分基准

尤其如果对方不是德国母语者，那只能当“真人样本”，不能当“标准样本”。

`edge-tts` 也确实支持把文本直接写成 mp3，命令参数是 `--write-media`，并且可以用 `--voice` 指定声音。citeturn965879view1

你可以这样写：

```python
import asyncio
import edge_tts
from pathlib import Path

VOICE_FEMALE = "de-DE-KatjaNeural"
VOICE_MALE = "de-DE-ConradNeural"
VOICE_DEFAULT = "de-DE-FlorianMultilingualNeural"

FEMALE_ROLES = {"FRAU", "LISA", "EMMA"}
MALE_ROLES = {"MANN", "NICO", "MAX"}


def pick_voice(role: str) -> str:
    role = (role or "").strip().upper()

    if role in FEMALE_ROLES:
        return VOICE_FEMALE

    if role in MALE_ROLES:
        return VOICE_MALE

    return VOICE_DEFAULT


async def text_to_mp3(text: str, role: str, output_path: str):
    voice = pick_voice(role)

    Path(output_path).parent.mkdir(parents=True, exist_ok=True)

    communicate = edge_tts.Communicate(
        text=text.strip(),
        voice=voice,
        rate="+0%",
        volume="+0%",
        pitch="+0Hz",
    )

    await communicate.save(output_path)


# 示例
asyncio.run(
    text_to_mp3(
        text="Hallo, ich heiße Lisa. Ich lerne Deutsch.",
        role="LISA",
        output_path="audio/lisa_001.mp3"
    )
)
```

命令行测试也可以：

```bash
edge-tts --voice de-DE-KatjaNeural --text "Hallo, ich heiße Lisa." --write-media lisa.mp3
```

建议你最终用这个逻辑：

```text
角色名 -> 判断男女 -> 选择声音 -> 文本清洗 -> 生成 mp3 -> 写入 manifest.json
```

关键点：**不要把 “LISA:” 也读出来**。  
比如原文是：

```text
LISA: Hallo, Nico!
```


否则音频会变成“Lisa Doppelpunkt Hallo Nico”，很怪。这个坑像电缆头没压紧，后面必炸。

**它不是“德语音标体系本身”，而是“德语标准发音词典”。**

它里面一般会给：

| 内容 | 作用 |
|---|---|
| IPA 音标 | 词怎么读 |
| Betonung 重音 | 哪个音节重读 |
| 标准发音 | 德国标准德语的推荐读法 |

| 多种读法 | 有些词可能有变体 |

你要做德语发音系统，这本书可以作为**最高裁判**。

## 你的技术路线应该这样定

### 1. 音标体系：用 IPA

德语就用国际音标 IPA，例如：

```text
ich        [ɪç]
Buch       [buːx]
Vater      [ˈfaːtɐ]
arbeiten   [ˈaʁbaɪ̯tn̩]
Elektriker [eˈlɛktʁɪkɐ]
```

不要自己发明一套奇怪音标。  
你的系统底层统一用 IPA，最稳。

---

### 2. 标准参考：Duden

Duden 负责回答：

```text
这个词到底标准读法是什么？
重音在哪里？
长音还是短音？
ch 是 [ç] 还是 [x]？
r 是怎么弱化的？
外来词怎么读？
```

比如：

```text
China
Chemie
Chance
Garage
Restaurant
Ingenieur
```

这些词用普通规则容易翻车，Duden 就是查案卷的老法官。📘

### 3. 数据源：不要直接批量抄 Duden

这个很重要。

Duden 是版权书。  
你可以**学习、参考、人工校对**，但不要直接把里面 132000 个词批量录入你的公开 App。

更务实的做法是：

```text
公共数据源 / Wiktionary / 自建词表
        ↓
清洗成 IPA
        ↓
用 Duden 人工校对高频词和争议词
        ↓
形成自己的德语发音词库
```

**系统内部以 Duden 标准德语发音为目标。**

```json
{
```

不需要每天抱着 Duden 啃。  
它不是教材，是“发音字典”。

### 1. 查重音

```text

Automatisierung
Gebäudetechnik

```

这种专业词最怕重音错。

### 2. 查长短音

```text
Staat [ʃtaːt]
Stadt  [ʃtat]
bieten [ˈbiːtn̩]
bitten [ˈbɪtn̩]
```

长短音是德语发音的骨架，不是装饰品。

---

### 3. 查 ch / r / ig / tion

例如：

```text
ich    [ɪç]
Buch   [buːx]
richtig [ˈʁɪçtɪç] / [ˈʁɪçtɪk]
Information [ɪnfɔʁmaˈtsi̯oːn]
```

这些是德语发音系统里的“暗门”。

# 德语语音塑造：目录版本

## 1. 基础

### 1.1 音素与音标

德语学习要分清：

```text
字母 = 写法
音素 = 实际声音
音标 = 声音的符号
```

例如：

```text
ich     [ɪç]
Buch    [buːx]
Tag     [taːk]
Vater   [ˈfaːtɐ]
```

你要重新学的是 **声音系统**，不是单词拼写。

---

### 1.2 德语字母

重点不是 26 个字母，而是这些特殊关系：

```text
ä   [ɛ] / [ɛː]
ö   [œ] / [øː]
ü   [ʏ] / [yː]
ß   [s]
sch [ʃ]
ch  [ç] / [x]
sp  [ʃp]
st  [ʃt]
z   [ts]
v   常读 [f]
w   [v]
j   [j]
```

---

## 2. 发声器官

你要重点控制 6 个位置：

| 器官 | 作用 |
|---|---|
| 嘴唇 | 圆唇 / 扁唇 |
| 下巴 | 张口大小 |
| 舌尖 | 顶牙龈、顶下齿、放松 |
| 舌面 | 前、中、后 |
| 软腭 | 鼻音 / 非鼻音 |
| 声带 | 清音 / 浊音 |

德语发音的核心不是“使劲”，而是 **位置准确 + 长短准确 + 清浊准确**。

---

# 3. 音素详解

## 3.1 元音

德语元音最重要的三件事：

```text
1. 长短
2. 松紧
3. 圆唇
```

先按这个分组学。

---

## 3.1.1 a / aː

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [a] | Mann [man] | 嘴张大，舌头低，声音短 |
| [aː] | Name [ˈnaːmə] | 嘴张大，舌头低，声音拉长 |

训练：

```text
Mann     [man]
man      [man]
Name     [ˈnaːmə]
fahren   [ˈfaːʁən]
```

要点：

```text
[a]  短，干脆
[aː] 长，稳定，不要滑动
```

错误：

```text
不要把 [aː] 读成中文“啊～”那种夸张音。
德语长音是稳，不是唱。
```

---

## 3.1.2 iː / ɪ

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [iː] | bieten [ˈbiːtn̩] | 嘴角向两边，舌头高而靠前，长音 |
| [ɪ] | bitte [ˈbɪtə] | 嘴型稍松，舌头没有那么高，短音 |

最小对比：

```text
bieten   [ˈbiːtn̩]   提供
bitten   [ˈbɪtn̩]    请求

Miete    [ˈmiːtə]   房租
Mitte    [ˈmɪtə]    中间
```

嘴型口诀：

```text
[iː] = 紧、长、靠前
[ɪ]  = 松、短、靠前
```

这是德语里非常关键的一组。你之前问过 **bieten / bitte**，就卡在这里。

---

## 3.1.3 eː / ɛ / ɛː

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [eː] | gehen [ˈɡeːən] | 嘴半闭，舌头靠前，长而紧 |
| [ɛ] | Bett [bɛt] | 嘴更开，短而松 |
| [ɛː] | Mädchen [ˈmɛːtçən] | 嘴更开，长音 |

对比：

```text
Beet    [beːt]   花坛
Bett    [bɛt]    床

sehen   [ˈzeːən]
stellen [ˈʃtɛlən]
Mädchen [ˈmɛːtçən]
```

要点：

```text
[eː] 像“诶”但更稳、更窄
[ɛ]  像短促的“欸”
[ɛː] 是长的 [ɛ]
```

---

## 3.1.4 uː / ʊ

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [uː] | gut [ɡuːt] | 嘴唇圆，舌头高而靠后，长音 |
| [ʊ] | Mutter [ˈmʊtɐ] | 嘴唇圆但放松，短音 |

对比：

```text
gut      [ɡuːt]
Mutter   [ˈmʊtɐ]
Bus      [bʊs]
Blut     [bluːt]
```

要点：

```text
[uː] = 圆、紧、长
[ʊ]  = 圆、松、短
```

---

## 3.1.5 oː / ɔ

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [oː] | Boot [boːt] | 嘴唇圆，舌头靠后，长音 |
| [ɔ] | Bonn [bɔn] | 嘴张得更开，短音 |

对比：

```text
Boot    [boːt]   船
Bonn    [bɔn]    波恩

Ofen    [ˈoːfn̩]
offen   [ˈɔfn̩]
```

你之前问过：

```text
Boot
oben
Bohne
Bonn
```

这里核心就是：

```text
oː 长音：Boot / oben / Bohne
ɔ  短音：Bonn
```

---

## 3.1.6 yː / ʏ：ü 音

这是中国学习者的硬骨头。

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [yː] | Tür [tyːɐ̯] | 舌头保持 [iː] 的位置，嘴唇变圆 |
| [ʏ] | fünf [fʏnf] | 舌头靠前，嘴唇圆，短而松 |

练法：

```text
先发 [iː]
保持舌头不动
嘴唇慢慢变圆
得到 [yː]
```

训练：

```text
Tür      [tyːɐ̯]
über     [ˈyːbɐ]
fünf     [fʏnf]
müssen   [ˈmʏsn̩]
```

口诀：

```text
ü = i 的舌头 + u 的嘴唇
```

---

## 3.1.7 øː / œ：ö 音

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [øː] | schön [ʃøːn] | 舌头像 [eː]，嘴唇圆 |
| [œ] | öffnen [ˈœfnən] | 舌头像 [ɛ]，嘴唇圆，短音 |

练法：

```text
先发 [eː]
保持舌头
嘴唇变圆
得到 [øː]
```

训练：

```text
schön    [ʃøːn]
hören    [ˈhøːʁən]
öffnen   [ˈœfnən]
können   [ˈkœnən]
```

口诀：

```text
ö = e/ɛ 的舌头 + o 的嘴唇
```

---

## 3.1.8 ə / ɐ

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [ə] | bitte [ˈbɪtə] | 中央弱元音，轻轻带过 |
| [ɐ] | Vater [ˈfaːtɐ] | -er 结尾常弱化成 [ɐ] |

训练：

```text
bitte    [ˈbɪtə]
Name     [ˈnaːmə]
Vater    [ˈfaːtɐ]
Mutter   [ˈmʊtɐ]
```

关键：

```text
词尾 -e 不要读成中文“额”太重。
词尾 -er 不要读成完整 r。
```

## 3.1.9 双元音

德语核心双元音主要三个：

| 音 | 拼写 | 例词 |
|---|---|---|
| [aɪ̯] | ei / ai | mein, Mai |
| [aʊ̯] | au | Haus |
| [ɔʏ̯] | eu / äu | Deutsch, Häuser |

训练：

```text
mein      [maɪ̯n]
Haus      [haʊ̯s]
Deutsch   [dɔʏ̯tʃ]
Häuser    [ˈhɔʏ̯zɐ]
```

要点：

```text
双元音不是两个字分开读。
它是一个音从 A 滑到 B。
```

## 3.2.6 ç / x：两个 ch

这是德语发音的暗门。

| 音 | 例词 | 口腔位置 |
|---|---|---|
| [ç] | ich [ɪç] | 舌面靠近硬腭，气流摩擦 |
| [x] | Buch [buːx] | 舌后部靠近软腭，气流摩擦 |

规则：

```text
前元音后：ch = [ç]
i, e, ä, ö, ü 后面多为 [ç]

后元音后：ch = [x]
a, o, u, au 后面多为 [x]
```

例子：

```text
ich      [ɪç]
mich     [mɪç]
Bücher   [ˈbyːçɐ]

Bach     [bax]
Buch     [buːx]
auch     [aʊ̯x]
```

标准德语里 ich-Laut 和 ach-Laut 是互补分布，前元音后多为 [ç]，后元音后多为 [x]。citeturn940171search4

## 为什么不用音标也不行？

因为德语有几个地方，光看字母会被骗。

| 字母 | 实际发音 | 例子 |
|---|---|---|
| z | ts | zwei = **tsvai** |
| ei | ai | drei = **drai** |
| ie | 长 i | sieben = **zii-ben** |
| v | 常读 f | Vater = **fa-ter** |
| w | v | Wasser = **vas-ser** |
| ch | 两种音 | ich / Bach |
| -ig | 常读 ich | dreißig = **drai-sich** |
| r | 不等于中文 r | drei 里的 r 要弱化 |

所以问题不是“学不学音标”。

问题是：  
**不要学完整 IPA，先学德语常见发音地雷。**

---

你的句子：

| 德语 | 原形 | 意思 | 说明 |
|---|---|---|---|
| Ich | ich | 我 | 句首大写 |
| arbeite | arbeiten | 工作 | ich arbeite = 我工作 |
| mit | mit | 和……一起 / 使用 / 从事相关 | **固定接第三格** |
| Strom | der Strom | 电流 / 电力 | mit Strom = 和电力相关 |
| und | und | 和 | 连接词 |
| elektrischen | elektrisch | 电气的 | 因为后面是第三格复数，所以变成 **-en** |
| Anlagen | die Anlage | 设备 / 装置 / 系统 | 这里是复数 |

核心记住：

> **mit + 第三格**  
> **mit Strom** = 和电力有关

## 2. app.js

```javascript
let dictionary = {};

async function loadDictionary() {
  const response = await fetch("./dictionary.json");
  dictionary = await response.json();
}

function tokenize(sentence) {
  return sentence
    .replace(/[.,!?;:]/g, "")
    .split(/\s+/)
    .filter(Boolean);
}

function normalize(word) {
  return word.toLowerCase();
}

function createCard(originalWord, info) {
  const card = document.createElement("div");
  card.className = "card";

  if (!info) {
    card.innerHTML = `
      <div class="word unknown">${originalWord}</div>
      <div class="meaning">未收录</div>
      <div class="note">需要加入词库</div>
    `;
    return card;
  }

  card.innerHTML = `
    <div class="word">${originalWord}</div>
    <div class="lemma">原形：${info.lemma}</div>
    <div class="meaning">意思：${info.meaning}</div>
    <div class="note">词性：${info.type}</div>
    <div class="note">${info.note}</div>
  `;

  return card;
}

function analyzeSentence() {
  const input = document.getElementById("input").value;
  const result = document.getElementById("result");

  result.innerHTML = "";

  const words = tokenize(input);

  words.forEach(word => {
    const key = normalize(word);
    const info = dictionary[key];
    const card = createCard(word, info);
    result.appendChild(card);
  });
}

loadDictionary();
```

# 五、后面真正要升级的地方

你这个工具真正有价值的地方，不是“查单词”，而是处理德语变形。

比如：

```text
elektrischen → elektrisch
Anlagen → Anlage
arbeite → arbeiten
gearbeitet → arbeiten
mit dem Auto → mit + Dativ
```

所以后面要加三层：

## 第一层：高频词库

直接查：

```text
ich
du
er
mit
und
arbeiten
Strom
Anlage
elektrisch
```

## 第二层：变形词库

专门收：

```text
arbeite → arbeiten
arbeitest → arbeiten
arbeitet → arbeiten
gearbeitet → arbeiten

Anlage → Anlage
Anlagen → Anlage

elektrisch
elektrische
elektrischen
elektrischer
elektrischem
elektrisches
```

## 第三层：句法规则

识别这种结构：

```text
mit + Dativ
für + Akkusativ
in + Dativ/Akkusativ
ich + 动词-e
du + 动词-st
er/sie/es + 动词-t
```

这才是你要的“德语学习显微镜”🔬。

你要的是**中文内容 → 德语表达**，中间再绕英文，等于多加一层齿轮，可能会把意思磨薄。

---

### 3. 用德语提示词

适合以后你 B1 以后使用。

优点：

模型更容易进入德语语境，输出可能更自然。

缺点：

你如果提示词写得不准，模型会误解要求。

比如你想说“简单一点”，写成德语后可能变成“儿童化一点”，结果输出像小学生作文，不适合面试。

---

## 最适合你的提示词模板

直接用这个：

```text
请把下面中文内容改写成德语。

要求：
1. 使用 A1-A2 水平德语。
2. 每句话尽量短，8-12 个词。
3. 不使用复杂从句。
4. 少用 weil/dass/obwohl。
5. 适合德国 Ausbildung 面试口语。
6. 不要逐字翻译，要改成德国人能听懂的自然表达。
7. 保留必要专业词，例如 Elektroniker, Energie- und Gebäudetechnik, Windpark, elektrische Anlagen。
8. 输出三部分：
   - 德语版本
   - 中文逐句意思
   - 背诵提示

中文内容：
……
```

这个比单纯说“翻译成德语”强很多。

---

## 你要避免的提示词

不要只写：

```text
翻译成德语
```

这样模型容易输出 B2-C1 德语，漂亮但你背不下来。

也不要写：

```text
请自然地翻译成德语
```

“自然”这个词很危险。模型可能会自动升级成复杂表达。

---

## 最强做法

你可以这样分三步：

### 第一步：中文原意整理

先让模型把中文变成清楚、短句的中文。

### 第二步：转成 A1/A2 德语

限制句子长度和语法。

### 第三步：口语化修正

让它检查：

> 这段德语是否适合 Ausbildung 面试？有没有太难、太书面、太假？

---

## 你的最终原则

**中文控制，德语输出。**

你现在不是在考“提示词德语水平”，你是在训练“可背、可说、可面试”的德语材料。

所以别把刀磨成显微镜。能切菜、能上桌、能反复用，才是好刀。

对，这很正常。**德语查词不能只靠一个 App。**

你遇到“查不到”，通常不是软件坏，而是德语本身像一台带变形齿轮的机器 ⚙️：

## 为什么查不到？

### 1. 你查的是变形，不是原形

比如：

| 你看到的词 | 应该查 |
|---|---|
| gearbeitet | arbeiten |
| gelernt | lernen |
| Anlagen | Anlage |
| besseren | gut / besser |
| technischen | technisch |
| bin / ist / war | sein |

很多词典对变形支持差，所以你直接查句子里的形态，可能查不到。

### 2. 德语复合词太多

比如：

**Energie- und Gebäudetechnik**  
拆开查：

- Energie
- Gebäude
- Technik

再比如：

**Sicherheitsvorschriften**  
拆成：

- Sicherheit
- Vorschrift

德语经常把几个词焊成一个长词，像电缆接头一样，外面看是一根，里面其实有好几芯。

### 3. 可分动词会“断开”

比如：

**Ich rufe dich an.**

你查 `rufe`，可能不清楚。  
真正要查：

**anrufen**

再比如：

| 句子里 | 原形 |
|---|---|
| ich mache ... aus | ausmachen |
| ich schalte ... ein | einschalten |
| ich fange ... an | anfangen |

### 4. 专业词普通词典确实少

电气、风电、Ausbildung 相关词，比如：

- Schaltanlage
- Netzanschluss
- Schutztechnik
- Gebäudetechnik
- Inbetriebnahme
- Störungssuche

普通学习 App 可能查不到，或者解释很差。

## 你的最佳组合

不要纠结“哪个 App 一统天下”。直接分工：

**dict.cc**  
查单词、性别、固定搭配，离线备用。

**LEO**  
查常见词、例句、搭配，比很多小词典稳。

**DeepL / ChatGPT**  
整句解释、拆词、找原形。

**Forvo / Wiktionary**  
查真人发音或 IPA，但不是每个词都有。

**Edge TTS / iPhone 朗读**  
生成整句发音，用来跟读背诵。

## 你以后查词按这个流程

看到一个德语词，不要马上扔进词典。先问三个问题：

**第一：它是不是变形？**  
`gearbeitet → arbeiten`

**第二：它是不是复合词？**  
`Gebäudetechnik → Gebäude + Technik`

**第三：它是不是可分动词？**  
`schalte ... ein → einschalten`

然后再查。

## 最实用做法

你可以以后直接把一句德语发给我，让我输出这种格式：

```text
Ich arbeite in einem Windpark.

Ich = 我
arbeite → arbeiten = 工作
in = 在
einem → ein = 一个，第三格
Windpark = 风电场

整句：我在一个风电场工作。
发音重点：arbeite / Windpark
```

这比你一个个在 App 里挖词快很多。

最终建议：**dict.cc 保留，LEO 也保留。查不到的词，先让我拆原形和结构。**  
你的主线不是“找最完美词典”，而是建一个自己的德语拆词工作流。这个比换 10 个 App 更值。
