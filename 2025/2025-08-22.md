## 🍎 macOS 安装和使用 `yt-dlp` 教程

### 1️⃣ 安装 Homebrew（如果你还没装过）  
打开 **终端 (Terminal)**，输入：  
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```
安装完成后，先把 Homebrew 加到 PATH：  
```bash
echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile
eval "$(/opt/homebrew/bin/brew shellenv)"
```

---

### 2️⃣ 安装 `yt-dlp`  
在终端里执行：  
```bash
brew install yt-dlp
```

---

### 3️⃣ 下载视频  
举个例子，要下载某个 YouTube 视频：  
```bash
yt-dlp "https://www.youtube.com/watch?v=xxxxx"
```
（把 `xxxxx` 换成视频链接）

下载完成后，视频文件会保存在当前目录。  

---

### 4️⃣ 下载音频（mp3 格式）  
如果你只想要音频：  
```bash
yt-dlp -x --audio-format mp3 "https://www.youtube.com/watch?v=xxxxx"
```

---

### 5️⃣ 可选：下载到指定文件夹  
比如保存到桌面：  
```bash
yt-dlp -o "~/Desktop/%(title)s.%(ext)s" "https://www.youtube.com/watch?v=xxxxx"
```

这样下载后文件会直接出现在桌面，文件名就是视频标题。

## 🔧 解决步骤（macOS）

### 1️⃣ 安装 `yt-dlp` 的依赖
确保你已经装了：
```bash
brew install yt-dlp
brew install ffmpeg
```

---

### 2️⃣ 导出 YouTube cookies
最简单方法是用浏览器插件（推荐 Chrome/Edge/Brave/Safari 都行）：

1. 安装插件：  
   👉 [Get cookies.txt](https://chrome.google.com/webstore/detail/get-cookiestxt/bgaddhkoddajcdgocldbbfhplklejnkb)  

2. 打开 **YouTube 网站**（确保你已登录账号，可以正常看视频）。  

3. 点击插件，把 cookies 导出保存为 `cookies.txt`。  

---

### 3️⃣ 用 cookies 下载视频
在终端运行：  
```bash
yt-dlp --cookies ~/Desktop/cookies.txt "https://youtu.be/rEzEzSg4pAw"
```
（假设你把 `cookies.txt` 放在桌面）

---

### 4️⃣ 另一种更简单的方法（直接用浏览器 cookies）
如果你用的是 Chrome 或 Safari，可以让 `yt-dlp` 自动读取：  
```bash
yt-dlp --cookies-from-browser chrome "https://youtu.be/rEzEzSg4pAw"
```
（把 `chrome` 换成 `safari` 或 `edge`，根据你用的浏览器来写）

---

### 5️⃣ 如果还要下载音频（mp3）
```bash
yt-dlp --cookies-from-browser chrome -x --audio-format mp3 "https://youtu.be/rEzEzSg4pAw"
```

---

⚠️ 注意：
- 一定要保证你浏览器里能正常播放该视频。  
- 如果视频是 **年龄限制/地区限制**，用 cookies 方法基本就能解决。
