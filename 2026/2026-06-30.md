```

```

它只是**隐藏了秒**，并没有把秒删除。

例如：

| 实际值 | 显示 |
|--------|------|

所以实际上秒仍然存在。

### 如何验证

把格式改成：

```
yyyy/m/d h:mm:ss
```

或者

```
yyyy-mm-dd hh:mm:ss
```

秒就会显示出来。


Excel/WPS 的**时间值一定包含"天的小数"**，格式 `yyyy/m/d h:mm` 只是隐藏秒，实际秒仍然存在，所以相减时还是会受到秒影响。

```excel
=TRUNC(D2*1440)/1440
```

或

```excel
=INT(D2*1440)/1440
```

```

处理后：
2026/6/10 09:36:00

```

```
yyyy/m/d h:mm
```


- 仅修改格式 → 秒还在，相减会受影响。
