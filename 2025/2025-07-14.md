## 1️⃣ MP4 ➜ 字幕（语音识别）

### ✅ 推荐工具：`openai-whisper`

安装：
```bash
pip install git+https://github.com/openai/whisper.git 
brew install ffmpeg  # 确保 ffmpeg 可用
```

使用：
```bash
whisper your_video.mp4 --model medium --language Chinese --output_format srt
```

生成 `.srt` 字幕文件，兼容播放器、视频编辑软件。

---

## 2️⃣ MP4 ➜ 音频提取（无损）

使用 `ffmpeg`：

```bash
ffmpeg -i your_video.mp4 -vn -acodec pcm_s16le -ar 44100 -ac 2 output.wav
```

说明：
- `-vn`: 不保留视频流
- `pcm_s16le`: 无损格式，方便后期语音模型处理

---

## 3️⃣ 更换声音（换声 / 变声）

### ✅ 推荐路径：**RVC + So-VITS / GPT-SoVITS**

用 [**RVC (Retrieval-based Voice Conversion)**] 可实现现有音频换成其他音色（如女声、动漫声等）

开源项目参考（可本地跑）：
- [https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI](https://github.com/RVC-Project/Retrieval-based-Voice-Conversion-WebUI)

配置方式：
```bash
# 安装依赖
pip install -r requirements.txt
# 启动
python infer-web.py --colab --pycmd python3
```

需要准备：**目标声音的训练数据（音频+文本）**，或者使用开源的现成声线模型。

## ✅ 为什么可以共用一个环境？

- `whisper` 是基于 Python 的库，你用 `pip install` 安装即可。
- `ffmpeg` 是系统级工具（不是 Python 包），需要通过 Homebrew 或直接下载安装，**只要它在系统的 PATH 中**，Python 脚本调用时就能正常使用。
- `whisper` 内部就是调用 `ffmpeg` 来解码 `.mp4` 文件，所以两个工具配合使用非常常见。

---

## ✅ 推荐共用安装流程（Mac 上一步到位）

### 1️⃣ 安装 `ffmpeg`（系统级）
```bash
brew install ffmpeg
```
如果你没装 Homebrew，可以先安装：
```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

验证是否安装成功：
```bash
ffmpeg -version
```

---

### 2️⃣ 创建 Python 环境并安装 `whisper`
```bash
# 创建并激活虚拟环境（任选其一）
python3 -m venv whisper-env
source whisper-env/bin/activate

# 安装 whisper（建议使用 GitHub 版本）
pip install git+https://github.com/openai/whisper.git

# 或普通版本（速度快）
# pip install openai-whisper
```

---

### 3️⃣ 测试是否联通
```bash
whisper your_video.mp4 --model small --output_format srt
```

如果你没有 CUDA（即没有显卡支持），建议指定使用 CPU：
```bash
export PYTORCH_ENABLE_MPS_FALLBACK=1  # Mac 上用 MPS 加速
whisper your_video.mp4 --model small --output_format srt --fp16 False
```

在 Mac mini 上，如果你误删了文件，有以下几种方法可以尝试找回这些文件：

---

### ✅ **一、检查“废纸篓”**
1. 点击桌面右下角或 Dock 栏中的“废纸篓”图标；
2. 查看是否还有你删除的文件；
3. 找到后，右键点击 → 选择“放回”即可还原。

---

### ✅ **二、使用 Time Machine（如果开启了备份）**
1. 打开 Launchpad → 输入“Time Machine”并打开；
2. 选择你想恢复的日期和时间；
3. 找到想要恢复的文件，点击“恢复”。

⚠️ 要求你之前有配置过 Time Machine 并有备份磁盘。

---

### ✅ **三、使用 Mac 文件恢复软件**
如果废纸篓已经清空、也没开启 Time Machine，可以尝试第三方恢复工具：

- **Disk Drill（推荐）**
- EaseUS Data Recovery Wizard for Mac
- Stellar Data Recovery

🧭 使用方法（以 Disk Drill 为例）：
1. 官网下载安装 Disk Drill；
2. 运行软件 → 选择你的硬盘（通常是 Macintosh HD）；
3. 点击“扫描”；
4. 找到丢失的文件 → 选择“恢复”。

> ❗**注意事项**：  
在误删文件后**不要向这块磁盘写入新的数据**，避免数据被覆盖！

---

### ✅ **四、通过 iCloud 云端恢复（如有启用）**
1. 打开网页：https://www.icloud.com/
2. 登录 Apple ID；
3. 查看“iCloud 云盘” → “最近删除”；
4. 恢复你要的文件。

---

### ❌ **如果你使用了“安全删除”或磁盘抹除**
那就**无法恢复**，即使用专业软件也难以找回，因为数据已被彻底覆盖。
