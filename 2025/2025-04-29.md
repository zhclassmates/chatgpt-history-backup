## 3. 编写 Dockerfile

```dockerfile
# 1. 选用官方 Python 基础镜像并安装依赖
FROM python:3.9-slim

# 2. 安装系统依赖与 Whisper
RUN apt-get update && apt-get install -y ffmpeg && \
    pip install --no-cache-dir openai-whisper faster-whisper

# 3. 复制脚本到容器
WORKDIR /app
COPY transcribe.py .

# 4. 定义默认命令（可修改为你的脚本入口）
CMD ["python", "transcribe.py", "--input", "/data/mp3s", "--output", "/data/txt"]
```

- `ffmpeg`：用于音频预处理【turn0search6】。  
- 将本地 `transcribe.py` 脚本打包，脚本内部可使用 Faster-Whisper API 批量转录。

## 4. 示例转录脚本 `transcribe.py`

```python
import os, argparse
from faster_whisper import WhisperModel

parser = argparse.ArgumentParser()
parser.add_argument('--input',  required=True, help='MP3 文件夹路径')
parser.add_argument('--output', required=True, help='转录文本输出路径')
args = parser.parse_args()

# 初始化模型（大模型可换成 small/medium）
model = WhisperModel("large-v3", device="cuda", compute_type="int8_float16")

os.makedirs(args.output, exist_ok=True)
for fn in os.listdir(args.input):
    if not fn.lower().endswith('.mp3'): continue
    inpath  = os.path.join(args.input, fn)
    outpath = os.path.join(args.output, fn.replace('.mp3', '.txt'))
    if os.path.exists(outpath): continue

    segments, _ = model.transcribe(inpath, beam_size=5, language="zh")
    with open(outpath, 'w', encoding='utf-8') as f:
        for seg in segments:
            f.write(seg.text.strip() + "\n")
    print(f"Processed {fn}")
```

- 支持命令行 `--input`/`--output`，方便容器化部署参数化调用。

## 5. 构建与推送镜像

## 6. 在 Claw Cloud Run 部署

参考官方文档 “Deploy from Docker” 步骤：  
1. 控制台 → App Launchpad → **Create App** citeturn0search2  
2. 填写应用名称、选择刚推送的镜像 `registry.run.claw.cloud/.../whisper:latest`  
3. 配置资源：CPU、内存、GPU（如果可用）  
4. 挂载卷：将 `/data` 目录映射到你的外部存储（Google Drive/S3/ClawCloud Volume）  
5. 环境变量与命令行参数：  
   - `CMD` 已在 Dockerfile 指定，若需自定义可在界面填入  
6. 点击 **Deploy**，几分钟后应用即启动并可访问日志与状态

- 在容器中放入 `/data/mp3s` 文件夹，部署时已挂载至外部存储  
- 容器启动后会自动遍历并生成 `/data/txt` 下的 `.txt` 文件  
- 可在控制台日志查看实时进度，也可通过 SSH/Exec 进入容器手动检查

## 8. 监控与扩容

- Claw Cloud Run 支持**自定义伸缩规则**，可按 CPU/GPU 利用率或队列长度自动扩容/缩容

## 9. 小贴士

- **切分长音频**：对于超长文件，先用 `ffmpeg` 分段再转录，避免 OOM。  
- **多模型版本**：可并行部署多个镜像，如 `small`、`medium` 版本，按资源和时延需求选择。  
- **日志输出**：在脚本中加日志文件，便于调试与失败重跑。
