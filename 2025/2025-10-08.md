# 方法 A —— 推荐（离线/断网后选择“限量体验”）
1. 安装到出现网络/登录那一步时：**断开网络**（拔网线、关闭路由器 Wi-Fi，或如果是笔记本按电脑的 Wi-Fi 开关断网）。  
2. 点击 **下一步/继续**。安装程序通常会显示 “无法连接到互联网” 的提示，并出现 **“我没有互联网（I don’t have internet）” / “有限体验（Limited experience）”** 的选项。  
3. 选择 **离线帐户/有限体验**，然后输入你想要的本地用户名和密码，完成剩余安装步骤。  
（这是最简单、最安全的方法。）

---

# 方法 B —— 安装界面没有“离线账户”选项时（使用命令行临时建本地管理员）
如果安装界面强制要求 Microsoft 账户，可以在 OOBE 阶段用命令行临时建一个本地管理员账户：

1. 在要求输入账号的 OOBE 界面按 **Shift + F10**，打开命令提示符（CMD）。  
2. 在命令提示符输入（把 `用户名` 和 `密码` 换成你想用的）：
```
net user 用户名 密码 /add
net localgroup administrators 用户名 /add
```
例如：
```
net user sheng 12345678 /add
net localgroup administrators sheng /add
```
3. 关闭 CMD（输入 `exit`），返回安装界面，然后重启或继续，使用刚建的本地用户登录。  

> 提示：如果系统在创建后仍不让你继续，输入 `shutdown /r /t 0` 在 CMD 里重启一次，应该就能使用新建的本地账户登录。

---

# 方法 C —— 如果以上都没用（极少见）
- 在创建账号那一步输入一个临时或无效邮箱（如 `no@mail.com`）和密码，有时安装器会提示“无法验证”，接着提供“创建本地账户”的选项。  
- 或者使用带有最新映像的安装介质（比如微软官网最新 Windows 10 ISO），某些旧或定制安装镜像会改变 OOBE 行为。

---

### ✅ **能用的版本**
- **Windows 10 21H2 及之前**：基本都能成功跳出“创建本地账户”界面。  
- **Windows 11 21H2、22H2 早期版本**：仍可使用，点击后会直接进入“输入用户名”的窗口。

---

### ❌ **失效的情况**
- **Windows 11 23H2 或更新（2024/2025年之后的版本）**：微软已经**禁用了**这个协议（`ms-cxh://localonly`），执行后可能**没有反应**或直接报错。  
- 原因是微软希望用户使用 Microsoft 账户联网设置。

---

### 🔧 **替代方案**
如果你用的是新版 Windows 11（比如 23H2 或 24H2），可以改用以下方法：

#### 方法 1：断网 + 错误登录法（最简单）
1. 到“登录 Microsoft 账户”界面时，**断网**（拔网线或关闭 Wi-Fi）。
2. 输入一个假邮箱，比如：`a@a.com`  
3. 密码随便填。  
4. 它会提示“出现问题”“无法登录”，然后自动出现“创建本地账户”的选项。

#### 方法 2：用命令行强制创建本地管理员
按下 **Shift + F10** → 输入以下命令：
```cmd
net user user1 123456 /add
net localgroup administrators user1 /add
```
然后输入：
```cmd
shutdown /r /t 0
```
重启后你就可以用这个本地账户 `user1`（密码 123456）登录系统。
