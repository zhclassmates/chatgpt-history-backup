# 一、先说结论（避免走弯路）

👉 **纯大模型 = 做不到毫秒级**  
👉 **必须混合架构：规则 + 词典 + 小模型 + 缓存**

目标拆解：

- 语音响应：< 300ms（用户体感“实时”）
- 文本翻译：< 50ms（短句）
- 全链路（说→听）：< 800ms

---

# 二、系统总架构（最优解）

```
麦克风
  ↓
VAD（语音检测）
  ↓
ASR（语音转文字）
  ↓
翻译引擎（分层）
  ↓
TTS（语音合成）
  ↓
扬声器
```

关键在中间这层👇

```
翻译引擎 =
  ① 高频短句缓存（0ms）
  ② 规则模板（5ms）
  ③ 词典拼接（10ms）
  ④ 小模型推理（50~150ms）
```

👉 像四道防线，越靠前越快
