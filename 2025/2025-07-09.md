**MediaCrawler** 是一个 Multi‑platform 的自媒体公开内容爬虫工具，支持爬取如下平台的公开信息（包括视频、评论、点赞、转发等）citeturn0search0turn0search1：

- 小红书、抖音、快手、B站、微博、百度贴吧、知乎  
- 支持关键词搜索、指定帖子/视频ID爬取、爬取二级评论、抓取指定创作者主页  
- 登陆缓存、本地保存、IP代理池、生成评论词云等特性citeturn0search0turn0search1  

---

## ⚙️ 技术及整体架构

- 使用 **Playwright** 浏览器自动化框架模拟登陆，保留登录状态  
- 无需 JS 逆向，直接通过浏览器上下文执行 JS 获取签名，大幅降低复杂度 citeturn0search0turn0search1

## 🚀 快速上手指南（简化版）

1. **准备依赖**：  
   - 安装 [uv](https://github.com/pdm-project/uv)：推荐用于 Python 包管理  
   - 安装 **Node.js（≥16）** 和 **Python（推荐3.7–3.9）** citeturn0search0turn0search5  

2. **安装依赖与驱动**：
   ```bash
   cd MediaCrawler
   uv sync                # 或使用 venv + pip install -r requirements.txt
   uv run playwright install     # 安装 Playwright 浏览器驱动
   ```

3. **配置爬虫功能**：  
   - 在 `config/base_config.py` 中设置 `ENABLE_GET_COMMENTS = True` 来启用评论爬取citeturn0search0turn0search5  

4. **运行爬虫任务**：
   - 关键词搜索爬取：
     ```bash
     uv run main.py --platform xhs --lt qrcode --type search
     ```
   - 指定帖子/视频 ID 爬取：
     ```bash
     uv run main.py --platform xhs --lt qrcode --type detail
     ```
   - 不用 uv 的话，可替换为 Python + pip：
     ```bash
     python main.py --platform xhs --lt qrcode --type search
     ``` citeturn0search0turn0search5  

5. **登录方式**：  
   - 支持二维码登录、cookie 本地保存，部分平台有手机号登录支持citeturn0search5  

6. **数据存储**：  
   - 支持存入 **MySQL**（需先创建数据库并初始化表），也可保存为 **CSV** 或 **JSON** 文件citeturn0search0turn0search5
