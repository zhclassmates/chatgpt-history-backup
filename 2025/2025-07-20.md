## ✅ 当前微信小程序方案（简化版）

### 🎯 目标功能（MVP）
- 用户点击“开始面试”按钮
- 系统从固定题库中**随机抽取一道题目**
- 展示题目后，用户**开始录制视频回答**
- 录制结束后，视频**保存在用户本地**
- 用户可**回放录制的视频**查看表现

---

### 🔧 技术方案简述

#### 1. 题目系统（固定题库）
- 后端提供接口：`GET /api/random-question`
- 前端调用接口获取随机题目展示
- 题库结构简单：`id`, `content`, `category`, `difficulty`

#### 2. 视频录制与本地存储
- 使用微信小程序 `<camera />` 组件进行视频录制
- 使用 `wx.createCameraContext()` 启动录制
- 录制完成后：
  - 视频使用 `wx.saveFile()` 存储至本地文件系统
  - 路径保存在前端页面状态中

#### 3. 视频回放
- 使用 `<video src="{{savedFilePath}}" controls />` 组件播放本地保存的视频

### 🧠 核心点 & 易错点

| 分类 | 核心点 | 易错风险 | 解决策略 |
|------|--------|----------|-----------|
| 题库 | 随机题目 | 题库过少、重复 | 后端做随机控制或标记历史记录 |
| 视频录制 | 摄像头权限 | 用户未授权 | 使用 `wx.authorize` 提前申请权限 |
| 本地存储 | 文件保存 | 视频过大/路径失效 | 限时录制（如3分钟），检测保存结果 |
| 回放 | 播放失败 | 本地路径不对/格式问题 | 录制后立即预览校验可用性 |

## 📦 GitHub 题库数据设计

你可以把题目存成 JSON 文件，托管在公开仓库：

`https://raw.githubusercontent.com/你的用户名/你的仓库名/main/question-bank.json`

### ✅ 示例 `question-bank.json` 文件结构：
```json
[
  {
    "id": 1,
    "content": "请介绍一下你自己",
    "category": "通用"
  },
  {
    "id": 2,
    "content": "谈谈你为什么想加入我们公司",
    "category": "求职动机"
  }
]
```

### 🚀 获取题目的方式（小程序端）：
```javascript
wx.request({
  url: 'https://raw.githubusercontent.com/你的用户名/你的仓库名/main/question-bank.json',
  method: 'GET',
  success: (res) => {
    const questionList = res.data
    const randomIndex = Math.floor(Math.random() * questionList.length)
    this.setData({
      currentQuestion: questionList[randomIndex].content
    })
  }
})
```

### 2. 面试页（Interview）

#### 功能点：
- 加载 GitHub 的题目列表
- 随机抽选一道题展示
- 视频录制（使用 `<camera/>`）
- 保存视频至本地临时路径
- 显示 `<video>` 组件供回放

#### 简要代码结构（面试页）：

```html
<view>
  <text>面试题目：</text>
  <text>{{currentQuestion}}</text>

  <camera device-position="front" flash="off" style="width:100%; height:300px;" bindinitdone="onCameraReady" />
  
  <button bindtap="startRecording">开始录制</button>
  <button bindtap="stopRecording">结束录制</button>

  <video src="{{videoPath}}" controls autoplay></video>
</view>
```

```javascript
Page({
  data: {
    currentQuestion: '',
    videoPath: ''
  },

  onLoad() {
    wx.request({
      url: 'https://raw.githubusercontent.com/你的用户名/你的仓库名/main/question-bank.json',
      success: (res) => {
        const questions = res.data
        const rand = Math.floor(Math.random() * questions.length)
        this.setData({
          currentQuestion: questions[rand].content
        })
      }
    })
  },

  startRecording() {
    this.cameraContext = wx.createCameraContext()
    this.cameraContext.startRecord({
      success: () => console.log('开始录制')
    })
  },

  stopRecording() {
    this.cameraContext.stopRecord({
      success: (res) => {
        wx.saveFile({
          tempFilePath: res.tempVideoPath,
          success: (saveRes) => {
            this.setData({
              videoPath: saveRes.savedFilePath
            })
          }
        })
      }
    })
  }
})
```

## ⚠️ 易错点与注意事项

| 问题 | 原因 | 解决办法 |
|------|------|----------|
| GitHub 加载失败 | 网络问题或URL错误 | 确保 GitHub 地址 raw 格式、仓库为公开 |
| 摄像头权限未开启 | 用户第一次使用 | 调用 `wx.authorize` 请求 camera 权限 |
| 本地存储失败 | 文件过大或路径失效 | 限制时长、检查 `wx.saveFile()` 成功回调 |
| 视频播放失败 | 播放路径失效 | 检查 `savedFilePath` 是否正确设置 |
