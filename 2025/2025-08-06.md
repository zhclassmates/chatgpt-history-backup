## ✅ 一、硬件串口通信说明

**目标：**
- Arduino 控制旋转台转动一小步

## ✅ 二、Arduino 控制步进电机并发串口信号

### 🔌 接线说明：
- `DIR` 接 Arduino D2（方向）
- `STEP` 接 D3（步进脉冲）
- `GND`, `VCC` 接好 A4988 的供电
- 连接 USB 到电脑（串口通信）

### ✅ 示例代码：

```cpp
#define DIR 2
#define STEP 3

void setup() {
  pinMode(DIR, OUTPUT);
  pinMode(STEP, OUTPUT);
  Serial.begin(9600);
  digitalWrite(DIR, HIGH); // 顺时针
}

void loop() {
  for (int i = 0; i < 200; i++) { // 每次转 1.8°（假设200步是5°）
    digitalWrite(STEP, HIGH);
    delayMicroseconds(800);
    digitalWrite(STEP, LOW);
    delayMicroseconds(800);
  }

  Serial.println("OK"); // 发送信号给 Python
  delay(1500);          // 等待摄像头拍照
}
```

⚠️ 每次循环就是“转一小段 → 发OK → 等待摄像头拍照”。

## ✅ 三、Python 自动拍照并保存图像

### ✅ 示例 Python 脚本：

```python
import serial
import cv2
import os
import time

# ✅ 设置串口（替换为你自己的）
SERIAL_PORT = "COM3"  # Windows 通常是 COMx，Linux 是 /dev/ttyUSB0
BAUD_RATE = 9600
IMAGE_DIR = "frames"

os.makedirs(IMAGE_DIR, exist_ok=True)

# ✅ 初始化串口和摄像头
ser = serial.Serial(SERIAL_PORT, BAUD_RATE, timeout=1)
cap = cv2.VideoCapture(0)

frame_index = 0
TOTAL_FRAMES = 72  # 你要转几圈就设置多少帧

print("等待 Arduino 信号...")

while frame_index < TOTAL_FRAMES:
    line = ser.readline().decode("utf-8").strip()
    if line == "OK":
        ret, frame = cap.read()
        if not ret:
            print("❌ 摄像头读取失败")
            continue
        filename = os.path.join(IMAGE_DIR, f"frame_{frame_index:03}.jpg")
        cv2.imwrite(filename, frame)
        print(f"✅ 第 {frame_index+1}/{TOTAL_FRAMES} 张已保存：{filename}")
        frame_index += 1

cap.release()
ser.close()
print("🎉 所有图像采集完毕")
```

### ✅ A4988 **供电双路系统：**

| 电源类型    | 用途           | 接线                        |

## 🧩 二、28BYJ-48 电机结构说明

| 线颜色     | 说明         |

### ✅ 示例代码（每次转 5°，转完发送 `OK` 给 Python）：

```cpp
#include <Stepper.h>

const int stepsPerRevolution = 2048;  // 28BYJ-48 一圈是 2048 步
Stepper myStepper(stepsPerRevolution, 8, 10, 9, 11); // 注意引脚顺序

void setup() {
  Serial.begin(9600);
  myStepper.setSpeed(10);  // 速度：转速RPM，可调
}

void loop() {
  myStepper.step(28);  // 28 步 ≈ 5°
  Serial.println("OK");  // 通知 Python 拍照
  delay(1500);  // 等待旋转和拍照
}
```
