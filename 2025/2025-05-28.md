## ✅ 推荐：**遥控小车式 + 小道具反应**

**核心玩法结构：**

- 小程序中控制按钮（↑ ↓ ← → / 加速 / 打印 / 旋转）
- 设备上表演“执行动作”：
  - LED 灯亮、马达旋转、发出声音
  - 完成任务 → 吐出纸条 → 打印结果
- 打印内容带昵称、抽签结果、趣味回复
- 最后提示：“谢谢参与！下一位！”

- 🐑 **仪式感适中**：不至于太过复杂，也不失小惊喜。
- 🤳 **截图传播友好**：打印出“××上上签”、“××好运到”可截图、发朋友圈。

## 🧠 简版代码（Node.js + Express）

### 1️⃣ `index.js`

```js
const express = require('express');
const fs = require('fs');
const cors = require('cors');
const app = express();
const PORT = 3000;

app.use(cors());
app.use(express.json());

let commandStore = {};  // { device_id: { action: "rotate", speed: "fast" } }

// 小程序下发指令
app.post('/api/control', (req, res) => {
  const { device_id, action, speed } = req.body;
  if (!device_id || !action) {
    return res.status(400).json({ error: '缺少参数' });
  }

  commandStore[device_id] = { action, speed, ts: Date.now() };
  res.json({ status: 'ok' });
});

// ESP8266 拉取指令
app.get('/api/poll', (req, res) => {
  const { device_id } = req.query;
  if (!device_id) return res.status(400).json({ error: '缺少device_id' });

  const cmd = commandStore[device_id] || { action: 'idle' };
  res.json(cmd);
});

// ESP 回传状态（可选）
app.post('/api/status', (req, res) => {
  const { device_id, status } = req.body;
  console.log(`设备 ${device_id} 状态：${status}`);
  res.json({ ok: true });
});

app.listen(PORT, () => {
  console.log(`控制服务器运行于 http://localhost:${PORT}`);
});
```

### ✅ 激光雕刻在食品表面后，还能不能吃？

答案是：**在特定条件下，可以吃，但有前提。**

---

## 🔥 激光雕刻的原理简述：
激光头发出高能量光束，烧灼或汽化物体表面材料，形成图案。过程伴随局部高温（200℃ 以上），并产生烟雾。

---

## 🍽️ 食品雕刻是否安全的关键在于：

### ✅ **可以吃的情况：**
1. **雕刻在硬壳类食物表面**：
   - 如：带壳瓜子、花生壳、核桃壳、带皮橘子、鸡蛋壳。
   - **理由**：雕刻不会穿透壳层，内部食用部分未受热或污染。

2. **使用低功率激光（≤500mW），快速雕刻**：
   - 减少焦糊物质生成，避免过度碳化。
   - 仅产生图案，不影响内部风味和安全性。

3. **设备干净、无毒材料**：
   - 激光雕刻设备未用过其他材料（如塑料、皮革），避免交叉污染。
   - 雕刻平台无重金属或油漆等有毒物质。

---

### ❌ **不建议吃的情况：**
1. **雕刻在食用部分上**（如苹果、饼干、熟食表面）：
   - 表层碳化物会生成**多环芳香烃**（PAHs），是一类潜在致癌物。
   - 激光过程中形成的焦味、杂味影响口感。

2. **使用大功率激光**（如 2000mW 以上）：
   - 极易焦化，甚至穿透食品表面，破坏营养与安全性。

3. **雕刻区域变黑、有焦味或烟灰残留**：
   - 表示局部炭化，建议**不食用**该区域。

---

| 食品类型 | 是否建议雕刻 | 雕刻后是否能吃 | 备注 |
|----------|----------------|----------------|------|
| 瓜子（带壳） | ✅推荐 | ✅可以吃内部 | 外壳雕刻图案 |
| 花生（带壳） | ✅推荐 | ✅可以吃内部 | 外壳变黑问题小 |
| 核桃、坚果 | ✅推荐 | ✅可以吃内部 | 装饰性强 |
| 苹果 | ❌不推荐 | ❌变味、炭化 |
| 饼干蛋糕 | ❌不推荐 | ❌不健康，易糊 |
| 糖果巧克力 | ❌不推荐 | ❌熔化或碳化 |
| 蔬菜表面 | ❌不推荐 | ❌炭化问题严重 |
