# 1️⃣ 德语有没有“类似1000h那种音素体系资料？”
有，而且更标准化，核心来源是：

## 🧠 IPA + 德语音系（Hochdeutsch）
德语标准发音基本就是：

- 一套 **IPA 音素表（Phoneme Inventory）**
- + 一个稳定的“高地德语标准音”（Standard German / Bühnendeutsch）

对应结构和英语完全一样：

> 音素系统 = 元音 + 辅音 + 超音段（重音/长短/节奏）

---

# 2️⃣ 德语音素系统（核心结构）
直接给你“德语版1000h风格结构”👇

## 🔵 元音 Vowels（核心）
德语元音系统比英语“更规则但更密集”

### 单元音（长短对立是核心）

| 短音 | 长音 | 例子 |
|------|------|------|
| ɪ | iː | bitte / bieten |
| ɛ | eː | Bett / Beet |
| a | aː | Mann / Vater |
| ɔ | oː | Sonne / Sohn |
| ʊ | uː | Mutter / Schule |

### 🧬 特殊元音（德语关键难点）
| 音 | 示例 |
|----|------|
| yː / ʏ | über |
| øː / œ | schön / können |
| ə | bitte（弱化e） |
| ɐ | Vater尾音 |

---

## 🟣 双元音 Diphthongs
只有3个（非常干净）

- aɪ → Ei
- aʊ → Haus
- ɔʏ → neu

👉 这一点比英语简单很多

---

## 🟡 辅音 Consonants（关键差异点）
德语的“标志性声音系统”：

### 1️⃣ 典型德语音
- x → Bach（喉音 ch）
- ç → ich（软ch）
- ʁ → R（法式/喉音R）

### 2️⃣ 清浊系统（比英语更稳定）
- p / b
- t / d
- k / g

但注意：
👉 词尾“清化”（很关键）

例：
- Tag → [taːk]
- Hand → [hant]

# 3️⃣ 德语有没有“可视化IPA音素图谱”？
有，而且比英语更成熟👇

## 📊 经典资源类型

### 🧭 ① IPA 音位表（最标准）

👉 推荐关键词：

- 每个词有 IPA

比如：

# 4️⃣ 你要的“1000h风格德语音素系统”可以怎么做？
这个是重点👇（直接给你结构）

你可以做一个：

## 🧠 德语 G2P 音素学习系统（建议结构）

### Layer 1：音素表
- IPA phoneme list（全部音）

### Layer 2：最小对立对（minimal pairs）
- bitten / bieten
- Stadt / Staat

### Layer 3：音位规则
- 词尾清化
- 长短音规则
- ch 两种音（ich / ach）

### Layer 4：G2P（Grapheme → Phoneme）
- 字母 → 发音映射

例：
- ie → iː
- ei → aɪ
- ch → ç / x

### Layer 5：可视化训练
- 音素卡片（Anki）
- 发音轨迹（嘴型+舌位）

# 🧩 Python IPA 生成器 v1（可直接跑）

```python id="ipa_gen_v1"
import json

class GermanG2P:

    def __init__(self, phonemes, rules):
        self.phonemes = phonemes
        self.rules = sorted(
            rules["rules"],
            key=lambda x: -len(x["pattern"])
        )

    def apply_rules(self, word):
        i = 0
        result = []

        while i < len(word):

            matched = False

            for rule in self.rules:
                pat = rule["pattern"]

                if word[i:i+len(pat)].lower() == pat:

                    result.append({
                        "input": pat,
                        "output": rule["output"],
                        "rule": rule["id"]
                    })

                    i += len(pat)
                    matched = True
                    break

            if not matched:
                result.append({
                    "input": word[i],
                    "output": self.basic_map(word[i]),
                    "rule": "char_map"
                })
                i += 1

        return result

    def basic_map(self, char):
        mapping = {
            "w": "v",
            "z": "ts",
            "s": "s",
            "t": "t",
            "n": "n",
            "r": "ʁ",
            "a": "a",
            "e": "e",
            "i": "i",
            "o": "o",
            "u": "u"
        }
        return mapping.get(char.lower(), char)

    def to_ipa(self, segments):
        return "".join([s["output"] for s in segments])

    def explain(self, segments):
        return " ".join([s["output"] for s in segments])


# -------------------------
# Example usage
# -------------------------

phonemes = {}
rules = {
    "rules": [
        {"id": "r1", "pattern": "sch", "output": "ʃ"},
        {"id": "r2", "pattern": "ch", "output": "x"},
        {"id": "r3", "pattern": "ei", "output": "aɪ"},
        {"id": "r4", "pattern": "au", "output": "aʊ"},
        {"id": "r5", "pattern": "eu", "output": "ɔʏ"},
        {"id": "r6", "pattern": "z", "output": "ts"},
    ]
}

word = "Wasser"

print("Breakdown:", g2p.explain(segments))
```

# ⚙️ v2 Python 引擎（完整可运行）

```python id="g2p_v2"
import re

class GermanG2P_V2:

    def __init__(self, rules):
        self.rules = sorted(rules["rules"], key=lambda x: -len(x["pattern"]))

    # -------------------------
    # 1. 主入口
    # -------------------------
    def convert(self, word):
        original = word

        word = word.lower()

        trace = []

        # 1. grapheme parsing
        segments = self.segment(word, trace)

        # 2. context rules (ch, vowel env)
        segments = self.apply_context(segments, trace)

        # 3. syllable split (debug only)
        syllables = self.syllabify(segments, trace)

        # 4. final devoicing
        segments = self.devoice(segments, trace)

        ipa = "".join([s["out"] for s in segments])

        return {
            "word": original,
            "ipa": ipa,
            "segments": segments,
            "syllables": syllables,
            "trace": trace
        }

    # -------------------------
    # 2. 最大匹配分词
    # -------------------------
    def segment(self, word, trace):
        i = 0
        out = []

        while i < len(word):

            matched = False

            for r in self.rules:

                pat = r["pattern"]

                if word[i:i+len(pat)] == pat:

                    out.append({
                        "in": pat,
                        "out": r["output"],
                        "rule": r["id"]
                    })

                    trace.append(f"{pat} → {r['output']}")

                    i += len(pat)
                    matched = True
                    break

            if not matched:
                out.append({
                    "in": word[i],
                    "out": self.basic(word[i])
                })

                i += 1

        return out

    # -------------------------
    # 3. 基础映射
    # -------------------------
    def basic(self, c):
        return {
            "w": "v",
            "z": "ts",
            "s": "s",
            "t": "t",
            "n": "n",
            "r": "ʁ",
            "a": "a",
            "e": "e",
            "i": "i",
            "o": "o",
            "u": "u"
        }.get(c, c)

    # -------------------------
    # 4. ch / context engine
    # -------------------------
    def apply_context(self, segs, trace):

        for s in segs:

            if s["in"] == "ch":

                # 判断前一个元音
                prev = self.get_prev_vowel(segs, s)

                if prev in ["i", "e", "ä", "ö", "ü"]:
                    s["out"] = "ç"
                else:
                    s["out"] = "x"

                trace.append(f"ch context → {s['out']}")

        return segs

    # -------------------------
    # 5. 词尾清化
    # -------------------------
    def devoice(self, segs, trace):

        devoicing = {
            "b": "p",
            "d": "t",
            "g": "k",
            "v": "f"
        }

        for i, s in enumerate(segs):

            if i == len(segs) - 1:

                if s["out"] in devoicing:
                    trace.append(f"final devoicing {s['out']}→{devoicing[s['out']]}")
                    s["out"] = devoicing[s["out"]]

        return segs

    # -------------------------
    # 6. 音节切分（简化版）
    # -------------------------
    def syllabify(self, segs, trace):

        syllables = []
        current = ""

        vowels = set(["a", "e", "i", "o", "u", "ə", "ɪ", "ɛ", "ɔ", "ʊ", "y", "ø"])

        for s in segs:

            current += s["out"]

            if any(v in s["out"] for v in vowels):
                syllables.append(current)
                current = ""

        if current:
            syllables.append(current)

        trace.append(f"syllables: {syllables}")

        return syllables


# -------------------------
# Example
# -------------------------

rules = {
    "rules": [
        {"id": "r1", "pattern": "sch", "output": "ʃ"},
        {"id": "r2", "pattern": "ch", "output": "x"},
        {"id": "r3", "pattern": "ei", "output": "aɪ"},
        {"id": "r4", "pattern": "au", "output": "aʊ"},
        {"id": "r5", "pattern": "eu", "output": "ɔʏ"},
        {"id": "r6", "pattern": "z", "output": "ts"},
    ]
}

g2p = GermanG2P_V2(rules)

print(g2p.convert("Wasser"))
print(g2p.convert("Zeit"))
print(g2p.convert("ich"))
```

# ⚙️ v3 完整 Python 引擎（升级版）

```python id="g2p_v3"
class GermanG2P_V3:

    def __init__(self, rules, exceptions):
        self.rules = sorted(rules["rules"], key=lambda x: -len(x["pattern"]))
        self.exceptions = exceptions

    # -------------------------
    # 主入口
    # -------------------------
    def convert(self, word):

        if word in self.exceptions:
            return {
                "word": word,
                "ipa": self.exceptions[word],
                "source": "exception"
            }

        segs = self.segment(word.lower())

        segs = self.apply_context(segs)
        segs = self.apply_length(segs)
        segs = self.apply_stress(segs)
        segs = self.final_devoice(segs)

        ipa = "".join([s["out"] for s in segs])

        return {
            "word": word,
            "ipa": ipa,
            "segments": segs
        }

    # -------------------------
    # 1. 最大匹配
    # -------------------------
    def segment(self, word):

        i = 0
        out = []

        while i < len(word):

            matched = False

            for r in self.rules:

                pat = r["pattern"]

                if word[i:i+len(pat)] == pat:

                    out.append({
                        "in": pat,
                        "out": r["output"]
                    })

                    i += len(pat)
                    matched = True
                    break

            if not matched:
                out.append({
                    "in": word[i],
                    "out": self.basic(word[i])
                })
                i += 1

        return out

    # -------------------------
    # 2. 基础映射
    # -------------------------
    def basic(self, c):
        return {
            "w": "v",
            "z": "ts",
            "s": "s",
            "t": "t",
            "n": "n",
            "r": "ʁ",
            "a": "a",
            "e": "e",
            "i": "i",
            "o": "o",
            "u": "u"
        }.get(c, c)

    # -------------------------
    # 3. ch / vowel context
    # -------------------------
    def apply_context(self, segs):

        vowels_front = ["i", "e", "ä", "ö", "ü"]

        for s in segs:
            if s["in"] == "ch":

                prev = self.find_prev_vowel(segs, s)

                if prev in vowels_front:
                    s["out"] = "ç"
                else:
                    s["out"] = "x"

        return segs

    # -------------------------
    # 4. 元音长度系统
    # -------------------------
    def apply_length(self, segs):

        for i, s in enumerate(segs):

            if s["out"] in ["a", "e", "i", "o", "u"]:

                next_seg = segs[i+1]["out"] if i+1 < len(segs) else ""

                if next_seg in ["m", "n", "t", "k", "p", "s"]:

                    s["out"] = self.shorten(s["out"])

        return segs

    def shorten(self, v):
        return {
            "a": "a",
            "e": "ɛ",
            "i": "ɪ",
            "o": "ɔ",
            "u": "ʊ"
        }.get(v, v)

    # -------------------------
    # 5. 重音系统（简化版）
    # -------------------------
    def apply_stress(self, segs):

        if len(segs) == 0:
            return segs

        segs[0]["out"] = "ˈ" + segs[0]["out"]

        return segs

    # -------------------------
    # 6. 词尾清化
    # -------------------------
    def final_devoice(self, segs):

        devoicing = {
            "b": "p",
            "d": "t",
            "g": "k",
            "v": "f"
        }

        last = segs[-1]

        if last["out"] in devoicing:
            last["out"] = devoicing[last["out"]]

        return segs
```

德语拉丁字母：

> **26个（A–Z）**

和英语完全一样。

---

## 🧩 2. 额外字母（变音）

德语额外有 4 个“字符级变体”：

- ä
- ö
- ü
- ß

---

## 📊 总体：

| 类型 | 数量 |
|------|------|
| 基础字母 | 26 |
| 变音字符 | 4 |
| 总计 | 30个“书写单位” |

---

# 🧠 二、德语音素（Phoneme）

这里才是关键。

## 🧩 1. 音素总数

标准德语（Hochdeutsch）：

> 🔥 **约 40–45 个音素**

（不同语言学体系略有差异）

---

# 🧬 三、德语音素结构（真正重要）

德语不是“很多音”，而是“对立系统清晰”。

---

## 🟢 1. 元音（Vowels）

### 🔹 单元音（短/长对立）

| 短音 | 长音 |
|------|------|
| /ɪ/ | /iː/ |
| /ʏ/ | /yː/ |
| /ʊ/ | /uː/ |
| /ɛ/ | /eː/ |
| /œ/ | /øː/ |
| /a/ | /aː/ |

👉 核心规律：

> 德语 = “长度决定意义”

---

## 🟢 2. 双元音（Diphthongs）

3个核心：

- /aɪ̯/（ei, ai）
- /aʊ̯/（au）
- /ɔʏ̯/（eu, äu）

---

## 🟢 3. 辅音（Consonants）

关键音素：

| 音素 | 示例 |
|------|------|
| /p t k/ | 基础清辅音 |
| /b d g/ | 浊辅音 |
| /f v/ | f / w（英语v） |
| /s z/ | s / z |
| /ʃ/ | sch |
| /ç/ | ich |
| /x/ | Bach |
| /ʁ/ | r（德式） |
| /ts/ | z |
| /tʃ/ | tsch |

---

## 🧠 四、最重要的德语“核心难点音素”

这几个决定你是否“像德语”：

### 🔥 1. /ç/ vs /x/
- ich /ɪç/
- Bach /bax/

👉 语音分裂核心点

---

### 🔥 2. /ʁ/（R音）

- 喉音 /ʁ/
- 或轻卷舌弱化

👉 德语身份标志

---

### 🔥 3. 长短元音系统

- bitten /ˈbɪtn/
- bieten /ˈbiːtn/

👉 意义区分

---

### 🔥 4. 词尾清化

- Rad → /ʁaːt/
- Tag → /taːk/

👉 拼写 vs 发音反差

---

# 🧩 五、字母 vs 音素（核心关系）

这是你系统设计的关键：

---

## ❌ 不是：

> 1字母 = 1音

---

## ✅ 德语真实关系：

### 1️⃣ 1字母 → 多音

- r → /ʁ/ /ɐ/
- e → /e/ /ə/

---

### 2️⃣ 多字母 → 1音

- sch → /ʃ/
- ch → /ç/ 或 /x/
- ei → /aɪ/
- ie → /iː/
- tsch → /tʃ/

---

### 3️⃣ 无发音字母

- h（延长元音）
- e（弱化）

---
