## 🔑 解释一下 cookies 的情况
- 你导出的 **cookies.txt** 文件，本质上就是把浏览器里的「登录状态」复制出来。  
- 只要这些 cookies 没有过期，你就可以反复使用它们下载多个视频。  
- **但是：**
  - 有些 cookies（比如 Google 登录的 `SAPISID`、`HSID` 等）是有时效的，过期后就失效；
  - 另外，如果你在浏览器里登出账号、更换密码，旧 cookies 也会立刻失效。

---

## ✅ 实际使用建议
1. **一次导出的 cookies.txt**  
   - 通常能用几小时到几天（有时候甚至几周），这取决于 YouTube 给你设置的过期时间。  
   - 所以，你完全可以用它连续下载多个视频。  

2. **长期使用**  
   - 建议用 `--cookies-from-browser`，每次都直接读浏览器里的最新 cookies，不用重复导出。  
   - 命令示例：  
     ```bash
     yt-dlp --cookies-from-browser chrome "https://youtu.be/rEzEzSg4pAw"
     yt-dlp --cookies-from-browser chrome "https://youtu.be/另一个视频ID"
     ```

3. **如果一定要用 txt 文件**  
   - 就在需要的时候再导出一次新的 cookies.txt。  
   - 这样可以保证不会因为过期导致下载失败。

---

👉 总结：
- **一次导出的 cookies.txt 可以多次使用**，但会随着过期或账号状态变化而失效。  
- **最推荐的方法**：用 `--cookies-from-browser`，这样永远都是最新的 cookies。

```python
import sys
import os
import subprocess

def download_video(url, audio_only=False):
    # 保存路径：桌面
    desktop = os.path.expanduser("~/Desktop")
    output_template = os.path.join(desktop, "%(title)s.%(ext)s")

    # 基本命令
    cmd = [
        "yt-dlp",
        "--cookies-from-browser", "chrome",   # 从 Chrome 获取 cookies
        "-o", output_template,
        url
    ]

    # 如果只要音频
    if audio_only:
        cmd.insert(1, "-x")
        cmd.insert(2, "--audio-format")
        cmd.insert(3, "mp3")

    try:
        subprocess.run(cmd, check=True)
        print("✅ 下载完成，已保存到桌面")
    except subprocess.CalledProcessError as e:
        print("❌ 下载失败:", e)

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("用法:")
        print("  python yt.py <url>         下载视频")
        print("  python yt.py <url> --mp3   下载音频(MP3)")
        sys.exit(1)

    url = sys.argv[1]
    audio_only = len(sys.argv) > 2 and sys.argv[2] == "--mp3"

    download_video(url, audio_only)
```

import sys
import os
import subprocess

def download_channel(url, audio_only=False, limit=10):

if __name__ == "__main__":
    if len(sys.argv) < 2:
        print("用法:")
        print("  python yt_channel.py <频道链接>         下载频道前 10 个视频")
