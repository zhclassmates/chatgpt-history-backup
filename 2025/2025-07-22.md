   - 字长就是 CPU 一次能在内部寄存器里处理、传输或运算的数据位数。

2. **64 位意味着什么**  
   | 对比项 | 32 位 | 64 位 |
   |---|---|---|
   | 寄存器宽度 | 32 bit | 64 bit |
   | 最大逻辑地址空间\* | 4 GB（2³²） | 16 EB（2⁶⁴）理想上，但操作系统会做实际限制 |
   | 整数运算 | 一次最多处理 32 位整数 | 一次最多处理 64 位整数 |
   | 指令集 | IA-32、ARMv7 等 | x86-64、ARMv8 等 |
   \*注：地址空间是操作系统可直接寻址的内存范围，64 位系统实际通常支持几十 TB。

3. **为什么 lscpu 里同时出现 “32-bit, 64-bit”**

```js
Page({
  data: {
    questions: [],
    currentIndex: 0,
    question: {},
    audioContext: null
  },

  onLoad() {
    wx.cloud.init()
    const db = wx.cloud.database()
    db.collection('questions').get().then(res => {
      this.setData({
        questions: res.data,
        question: res.data[0]
      })
    })

    this.setData({
      audioContext: wx.createInnerAudioContext()
    })
  },

  playAudio() {
    const { question, audioContext } = this.data
    if (question.audio) {
      audioContext.src = question.audio
      audioContext.play()
    } else {
      wx.showToast({ title: '没有音频', icon: 'none' })
    }
  },

  nextQuestion() {
    const { questions, currentIndex } = this.data
    const nextIndex = (currentIndex + 1) % questions.length
    this.setData({
      currentIndex: nextIndex,
      question: questions[nextIndex]
    })
  },

  onUnload() {
    if (this.data.audioContext) {
      this.data.audioContext.destroy()
    }
  }
```

## 1. 云函数调用失败，提示 FunctionName 参数找不到（-501000）

错误核心是：

```
cloud.callFunction:fail Error: errCode: -501000 | errMsg: FunctionName parameter could not be found
```

这说明你调用云函数时，没有正确传入 `functionName` 参数，或者云函数根本没部署。

### 解决建议：
- 确认你在小程序端调用云函数时，代码类似下面：

```js
wx.cloud.callFunction({
  name: '你的云函数名',
  data: { /* 传给云函数的参数 */ }
})
```

- 云函数名（`name`）要和你云开发控制台中部署的云函数名字一致。
- 确认云函数已经正确上传和发布（可以在腾讯云开发控制台 → 云函数里检查）。
- 如果还没有云函数，请先写一个简单的云函数（例如返回面试题数据）并部署。

---

## 2. 网络请求失败，`net::ERR_CONNECTION_REFUSED`，`errno: 600001`

这个错误表明小程序客户端请求网络失败，可能原因：

- 服务器地址写错或服务器未启动（如果是自己搭建的服务）
- 微信小程序域名未配置或不在合法域名列表里
- 网络不通或被防火墙拦截

### 解决建议：
- 如果是调用外部API，确认该域名在小程序后台「业务域名」配置中已添加且已审核通过。
- 如果是本地测试接口，无法被小程序访问，需要部署到可公网访问服务器。
- 查看域名拼写是否正确。
- 也可能是网络环境临时问题，尝试更换网络测试。

---

## 3. 小程序本地报错提示

```
Setting data field "questionId" to undefined is invalid.
```

说明代码里给页面 `setData` 的字段 `questionId` 传了 `undefined`。一般是接口返回数据缺少这个字段导致。
