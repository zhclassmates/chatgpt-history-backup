## ✅ 如何解决屏幕熄灭问题？

你需要在进入摄像头录制页面时，**手动调用系统保活 API：**

### ✅ 方法一：开启保持屏幕常亮

```js
wx.setKeepScreenOn({
  keepScreenOn: true,
  success() {
    console.log("已保持屏幕常亮");
  },
  fail(err) {
    console.error("设置常亮失败", err);
  }
});
```

> 建议在调用 `<camera>` 的 `onReady` 或 `onLoad` 中调用这段代码。

### ✅ 方法二：退出页面后关闭常亮（可选）

```js

  keepScreenOn: false
```

```js
Page({
  data: {
    newQuestion: '',
    questionList: []
  },

  onLoad() {
    this.loadQuestions();
  },

  loadQuestions() {
    const list = wx.getStorageSync('questionList') || [];
    this.setData({
      questionList: list
    });
  },

  onInput(e) {
    this.setData({
      newQuestion: e.detail.value
    });
  },

  addQuestion() {
    const content = this.data.newQuestion.trim();
    if (!content) {
      wx.showToast({ title: '题目不能为空', icon: 'none' });
      return;
    }

    const list = this.data.questionList;
    const newItem = {
      id: Date.now(),
      content: content
    };
    list.push(newItem);
    wx.setStorageSync('questionList', list);

    this.setData({
      questionList: list,
      newQuestion: ''
    });
    wx.showToast({ title: '添加成功', icon: 'success' });
  },

  deleteQuestion(e) {
    const index = e.currentTarget.dataset.index;
    const list = this.data.questionList;
    list.splice(index, 1);
    wx.setStorageSync('questionList', list);
    this.setData({ questionList: list });
  },

  onEditInput(e) {
    const index = e.currentTarget.dataset.index;
    const value = e.detail.value;
    const list = this.data.questionList;
    list[index].content = value;
    wx.setStorageSync('questionList', list);
    this.setData({ questionList: list });
  },

  goBack() {
    wx.navigateBack();
  }
});
```

### 📲 二、小程序中代码实现

#### 1. 在 `pages/interview/interview.js` 中：

```js
Page({
  data: {
    questionList: [],
    currentQuestionIndex: 0,
    audioContext: null
  },

  onLoad() {
    this.fetchQuestions();
  },

  fetchQuestions() {
    wx.request({
      url: 'https://wjz5788.github.io/interview-audio/questions.json',
      method: 'GET',
      success: (res) => {
        this.setData({
          questionList: res.data
        });
      },
      fail: () => {
        wx.showToast({
          title: '题库加载失败',
          icon: 'none'
        });
      }
    });
  },

  playAudio() {
    const { questionList, currentQuestionIndex } = this.data;
    const audioUrl = questionList[currentQuestionIndex].audio;

    if (!audioUrl) {
      wx.showToast({
        title: '没有音频链接',
        icon: 'none'
      });
      return;
    }

    const audio = wx.createInnerAudioContext();
    audio.src = audioUrl;
    audio.play();

    this.setData({ audioContext: audio });
  },

  nextQuestion() {
    const nextIndex = this.data.currentQuestionIndex + 1;
    if (nextIndex < this.data.questionList.length) {
      this.setData({ currentQuestionIndex: nextIndex }, () => {
        this.playAudio();
      });
    } else {
      wx.showToast({ title: '已经是最后一题了', icon: 'none' });
    }
  }
});
```

### 为什么还是报 “url not in domain list”？

`wx.request` 只能访问 **已添加到「request 合法域名」白名单** 的地址，而 GitHub Pages 默认不在名单里，所以真机 / 预览阶段都会直接失败。  
> 开发者工具里「忽略合法域名校验」可暂时绕过，但真机一定会报错。

---

## 解决方案 A（**零配置**，最推荐）

**改用 `wx.downloadFile + readFile`** ——无需把 GitHub 域名加到白名单，也无需云开发。

```js
// interview_step.js 内统一替换
loadQuestions() {
  const url = 'https://wjz5788.github.io/interview-audio/questions.json'
  wx.downloadFile({
    url,
    success: res => {
      // 读临时文件
      wx.getFileSystemManager().readFile({
        filePath: res.tempFilePath,
        encoding: 'utf-8',
        success: data => {
          this.setData({ questionList: JSON.parse(data.data) }, () => {
            this.pickRandomQuestion()
          })
        },
        fail: () => wx.showToast({ title: '题库读取失败', icon: 'none' })
      })
    },
    fail: () => wx.showToast({ title: '题库下载失败', icon: 'none' })
  })
}
```

- `downloadFile` 属于 **file** 域名，不受 request 域名白名单限制。  
- `readFile` 解析 JSON 后再 `setData` 即可。

> **同理**，`interview_full.js` 里也把 `wx.request` 改成这套逻辑即可。
