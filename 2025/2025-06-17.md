### 🔍 如果你想“查找本机 IP 地址”，请按操作系统选择：

#### ✅ 1. 如果是 Linux 系统（如银河麒麟、凝思 Linux）：
打开终端，输入命令：

```bash
ip addr show
```
或者更简洁：

```bash
ip a
```

你会看到如下输出：
```bash
2: ens33: <BROADCAST,MULTICAST,UP,LOWER_UP> ...
    inet 192.168.1.100/24 brd 192.168.1.255 scope global dynamic ens33
```

此处 `inet 192.168.1.100` 即为你的本机 IP。

---

#### ✅ 2. 如果系统较老或无 `ip` 命令，也可用：

```bash
ifconfig
```

（需要安装 `net-tools` 工具）

---

### 📡 查找**局域网中其他设备的 IP**（扫描网段）：

可使用如下命令（需 root 权限）：

```bash
nmap -sn 192.168.1.0/24
```

这会扫描整个 `192.168.1.x` 网段中在线的设备。

---

### 🧠 附加工具（可能需安装）：
- `nmap`：网络扫描工具
- `net-tools`：包含 ifconfig 等
- `iproute2`：提供 `ip` 命令

## ✅ 64 个电击孔底板 + 插杆 + 四叉结构模型（可导出 `.STEP`）

你可以直接复制以下代码粘贴到 CQ-Editor 左侧代码框中，运行后右侧看到 3D 模型，并在当前目录导出 3 个 `.step` 文件。

---

### 🧱 脚本如下：

```python
import cadquery as cq

# 参数设定
plate_size = 120          # 电击板尺寸 mm
hole_spacing = 15         # 孔距 mm
hole_diameter = 2.5       # 每个孔直径 mm
plate_thickness = 3       # 板厚 mm

pole_diameter = 2.0       # 杆直径 mm
pole_height = 100         # 杆高 mm

fork_arm_length = 12.5    # 每个叉臂长度 mm
fork_arm_diameter = 0.8   # 叉臂直径 mm

# 生成底板（含 8x8 打孔）
plate = cq.Workplane("XY").box(plate_size, plate_size, plate_thickness)
for i in range(8):
    for j in range(8):
        x = -plate_size/2 + hole_spacing/2 + i * hole_spacing
        y = -plate_size/2 + hole_spacing/2 + j * hole_spacing
        plate = plate.faces(">Z").workplane().pushPoints([(x, y)]).hole(hole_diameter)

cq.exporters.export(plate, "BasePlate.step")

# 单个杆模型
pole = cq.Workplane("XY").circle(pole_diameter / 2).extrude(pole_height)
cq.exporters.export(pole, "Pole.step")

# 单个叉模型（十字叉）
arm1 = cq.Workplane("XY").circle(fork_arm_diameter / 2).extrude(fork_arm_length)\
    .translate((0, 0, pole_height + 2))
arm2 = cq.Workplane("XY").circle(fork_arm_diameter / 2).extrude(fork_arm_length)\
    .rotate((0, 0, 0), (0, 0, 1), 90).translate((0, 0, pole_height + 2))

fork = arm1.union(arm2)
cq.exporters.export(fork, "Fork.step")

# 展示其中一个组合（预览用）
assembly = pole.union(fork)
show_object(assembly)
```
