你遇到的错误信息提示：

```
HTTP Error 429: Too Many Requests
```

这是因为 YouTube 检测到过多请求，怀疑是爬虫行为，导致你被暂时封锁访问（限流）。同时提示你需要登录并验证自己不是机器人。

### 解决办法如下：

#### ✅ 方法一：使用浏览器导出的 Cookie 文件
这是 yt-dlp 推荐的方式：

1. **使用浏览器登录你的 YouTube 账号**。
2. **导出 Cookies** 文件。推荐插件：[Get cookies.txt](https://chromewebstore.google.com/detail/get-cookiestxt/nibjkhiokphhbnjbkffhkhipcdgpcgfk)。
3. **保存导出的 cookies.txt 文件**，并确保路径和脚本中一致。例如你当前用的是：

   ```
   --cookies /Users/shengmo/Documents/github_project/cookies.txt
   ```

4. **确保该 cookies 文件是新的**，且包含登录状态，否则还是会出错。

#### ✅ 方法二：使用 `--cookies-from-browser`（更自动）
如果你安装的是最新版本的 yt-dlp，可以用这个命令直接调用本地浏览器的 Cookie，不需要手动导出：

```bash
yt-dlp --cookies-from-browser chrome "https://youtu.be/4ErJYWHFxNc"
```

前提是你用 Chrome 浏览器登录了 YouTube，并允许 yt-dlp 访问浏览器的 Cookie 数据。

#### 🔁 补充建议
- 等待一段时间再尝试，YouTube 的限流通常是临时的。
- 使用代理/VPN 可以更换 IP 地址，绕过限制。
- 使用 `--sleep-interval`、`--max-downloads` 等参数限制访问频率，减少被封概率。
